Документ показывает, где в коде реализован каждый результат теории, и с каким
эпистемологическим статусом (Q0 = тождество, Q1 = теорема, Q2 = аналитическое
следствие, Q3 = гипотеза, Q4 = соответствие источника).

- ε ≠ m — центральная гипотеза (Q3), закрывается протоколом IBM Quantum
  (κ_eff = a + b·ε_mix, детекция b≠0 на уровне 5σ).

- Прямое наблюдение перехода S6→S7 (Q2) — ультракороткая спектроскопия.
