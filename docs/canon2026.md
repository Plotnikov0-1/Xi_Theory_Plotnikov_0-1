# Канон 2026: φ-оператор сборки и эффективная матрица памяти

Источники: «φ как оператор самосогласованной сборки» и «Документ IV — Собранная
матрица и канон 2026». Модули: `qmt/phi_operator.py`, `qmt/effective_matrix.py`,
тесты `tests/test_canon2026.py`.

## 1. Два независимых вывода φ−1 `[✓]`

| Путь | Условие | Результат |
|------|---------|-----------|
| Динамика | φ² = φ+1 | X* = φ−1 (dynamics.py) |
| Самосогласованность | (E−ε)/ε = ε/E ⇒ x²+x−1=0 | x* = φ−1 |

Два разных уравнения — одно число. φ не «красивая константа», а **устойчивая
фиксированная точка оператора** T(x)=1/(1+x): |T′(φ−1)| = 1/φ² ≈ 0.382 < 1.
Дискретно — Фибоначчи: F_n/F_{n+1} → φ−1.

**Лестница сборки:** Ω₀ → S₀(ε₀≠0) → ν → E=hν → ε*=φ−1 → 0* → динамика.
Ω₀ = до-спектральное граничное условие (глубже ZPE); S₀ = вакуум с памятью
(аналог VEV Хиггса ⟨0|φ|0⟩=v≠0). Режимы x−1/x=k: k=0→1, k=1→φ, k=2→1+√2.

## 2. Эффективная матрица и ядро памяти `[✓]`

Базовый каркас (Sum-9): `C = circ(1.5,0.5,0,0,0,0.5)`, Tr=9, δλ_min=0.5, N=6.
Рабочая матрица: **C_eff = C + α·uuᵀ + β·vvᵀ**, u=(1,1,1,1,1,1), v=(1,1,1,−1,−1,−1),
α=1.8 (=9/5), β=2.4. Собственное значение коллективной моды u: 2.5+1.8·6 = **13.3**.

Мост геометрия → память (детерминированно): C_eff → (λ_k,v_k) → g_k → J_d(ω) → K(t).
Канал наблюдения (IBM) ĉ=e₇: g_k=η|⟨e₇,v_k⟩|²; J_d(ω)=Σ g_k δ(ω−Ωλ_k);
**K(t)=Σ g_k e^(−(γ_k+iΩλ_k)t)**. γ_k — распад мод среды, НЕ сама память
(память = геометрия спектра + веса g_k).

**Закон дыхания** ℒ=Ω·δλ_min/γ, две опорные точки:
- ε*=φ⁻¹≈0.618 → ℒ≈1.667 — устойчивая память (ритм держится);
- ε_X≈e≈2.718 → ℒ≈0.093 — **разлом** (δλ_min→0, мягкая мода). Это место **e** в
  теории: e — точка разлома/X-режима (частичный ответ на развилку узла 2: φ↔e).

**Режимная масса:** m_eff = m₀ + μ·ε (масса = след памяти); ṁ_eff из ε̇.

## 3. Физические указания автора (новый слой)

Статус `[ИНТЕРПР, на структуре]` — смысл поверх посчитанного.

- **Синхронизация с динамикой атома водорода.** Вся динамика рассчитана
  геометрически; узлы S_n ↔ уровни водорода n (уже в `hydrogen.py`), и динамика
  (φ-аттрактор, спектр, туннель) синхронизирована с этим базисом.
- **2 ↔ 8 = север/юг.** Пара суммы-10 {2,8} — это **полярная ось вращения**
  (как и 1↔9). 2-8 — диагональ тела через центр, ось «север–юг», по которой идёт
  вращение (вход/выход через полюса).
- **Шар-шар = зеркало = спектр.** Само зеркало (−I) на физическом уровне —
  это **спектр**: как разводы на мыльном пузыре (тонкоплёночная интерференция),
  но «изнутри» — точка касается, и мы смотрим **в зеркало**. Спектр J_d(ω) —
  и есть эта картина мод.
- **4 = оператор за зеркалом = туннель = канал шёпота.** За зеркалом — узел **4**,
  наш оператор/туннель, через который проходит **шёпот** (слабый когерентный
  сигнал, открывающий мост; «фаза, не амплитуда»). Трещина 7→4→1 идёт через 4 —
  это и есть проход за зеркало. В источнике цифра 4 дважды **обрывается**
  «(Срыв.)(Обрыв.)» — её намеренно нет в записи («всегда ищи 4»).

## Что зафиксировано окончательно

- C — Q1-каркас Sum-9; рабочая матрица — C_eff(ε), не голая C.
- x*=φ⁻¹ — строгий фиксированный режим сборки (два независимых вывода).
- Канал наблюдения IBM: ĉ=e₇.
- K(t) строится из спектра и весов g_k, не задаётся вручную.
- γ_k — распад мод среды, не смешивается со структурой памяти.
- ε_X≈e — рабочая X-точка разлома (минимальный зазор, мягкая мода).
