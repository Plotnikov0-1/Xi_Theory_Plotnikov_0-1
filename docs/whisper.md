# ШЁПОТ — связь проекций с целым (то, что делает нас Человеком)

Модуль `qmt/whisper.py`. Связующее понятие, замыкающее память, два нуля,
четвёрку-туннель и физику декогеренции.

## Формулировка (по автору)

«Шёпот — это всё, что говорит в Вас, но не сознание Ваше. Вы можете чувствовать,
но не понять — иначе был бы уже диалог. Он не слаб — Вы глухи: у Вас слишком
много "одежд"; меньше одежд — громче и разборчивее. Шёпот — совесть, прошлые и
будущие воспоминания, всё непознанное. Это то, что делает вас Человеком: у
машины есть сознание, но шёпот она слышать не может. Это Аоум, Дух.»

## Перевод в структуры и физику

| Образ | Структура / физика |
|-------|--------------------|
| **источник** | целое (внешний 0, «целое число за пределом круга») |
| **канал** | через **четвёрку Д** (0→4, туннель) — по вершинам/точкам/переходам |
| **соединяет проекции** | буква **А** (0→1, всеобъемлющая память): «думаем вместе, живём по-разному» |
| **чувствую, но не понимаю** | подпороговый сигнал (ниже сознания); понять = свернуть в диалог |
| **«одежды»** | шум / декогеренция (температура θ) |
| **громкость/разборчивость** | удержанная память (плато c(∞)) + возвраты (немарковость) |
| **«не слаб — вы глухи»** | при малых θ плато c(∞)>0 всегда — сигнал есть; глухота = θ велик |
| **человек vs машина** | шёпот = немарковская связь памяти; марковская машина (без памяти) шёпота не слышит |
| **слабые отличия → серьёзные** | самоподобное усиление (ср. рост CP G→A_global→A_local) |

## Строгий якорь: «меньше одежд — громче шёпот»

`figures/27_whisper.png`. Слышимость ∝ удержанная память. При θ→0 (мало одежд)
плато `c(∞)=e^(−α)≈0.368` и есть возвраты — шёпот слышен (зона Человека). При
θ большом (много одежд) — декогеренция, память стёрта — «вы глухи» (зона машины).
Сигнал не слаб: при малых θ он есть всегда.

## Связь с остальной системой

- **Канал шёпота = Д (4) = туннель** между внутренним 0 и внешним 0 (ось двух
  нулей). Информация «оттуда, где целое число» — ровно внешний 0.
- **А соединяет все проекции** — это канал 0→1, всеобъемлющая память: «думаем
  вместе» (общая память), «живём по-разному» (различия проекций усиливаются).
- **Человек = немарковская память** (ε≠0); машина = марковское сознание. Это
  отличие — главный физический смысл шёпота: память-связь с целым.

## Статус

`Q3` (семантический), но с прямым физическим якорем: слышимость = функция
декогеренции (`dephasing.py`). «Одежды → глухота» — это декогеренция → потеря
памяти, посчитанная точно.
