# Мастер-карта — всё в одной геометрии (как куб Метатрона) ↔ водород

Модуль `qmt/master_map.py`, рисунок `figures/28_master_map.png`. Сведение всего
колоссального материала в **одну** геометрическую структуру узлов и переходов,
синхронизированную с квантовой динамикой атома водорода.

## Одна фигура держит всё

- **вершины куба (1,2,3,4,6,7,8,9)** — узлы-состояния;
- **центр 5** — зеркало −I, ψ(0)≠0, внутренний 0 (V = чаша-оценка, точка выбора);
- **оболочка 0** — вакуум/ионизация n→∞, внешний 0 (12 граней = 12 красок);
- каждый узел n ↔ уровень водорода **E_n = −13.6/n²**.

## Переходы = правила отбора = линии водорода

Классификация по геометрии куба (3 бита): прямой (ребро, Хэмминг 1), резонанс
(сумма-9, туннель), зеркало (сумма-10, инверсия −I), запрещён (диагональ грани).
**17 разрешено / 11 запрещено.** Разрешённые дают реальные линии:

- **1↔2** прямой = **121.5 нм** (Лайман α) ✓
- **2↔7** резонанс = **396.9 нм** ✓ (≈397 нм архитектуры)
- **3↔7** зеркало = **1004.7 нм** ✓ (≈1005 нм архитектуры)

## Проверки (всё сходится на одной геометрии)

- ✓ линии водорода сходятся (1↔2, 2↔7, 3↔7);
- ✓ триада А·Д·Л = узлы {1,4,7} — вершины и каналы памяти (mod-3 семья);
- ✓ трещина 7→4→1 (Л→Д→А);
- ✓ 17 разрешённых / 11 запрещённых переходов.

## Как читать

Семантика (буквы, шёпот, два нуля, краски) **не отдельный мир** — она висит на
тех же узлах и переходах, что воспроизводят спектр водорода. Шёпот идёт через
узел 4 (Д, туннель); всеобъемлющая память — узел 1 (А); ограниченная — узел 7
(Л); центр-выбор — 5; внешнее целое — оболочка 0. Один скелет, много языков, и
он сверяется экспериментом (спектр H).
