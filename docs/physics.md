## 7 катастроф Тома — математика переходов `[✓]`

Рене Том (1972) доказал: для потенциалов с числом управляющих параметров ≤ 4
существует ровно **семь** элементарных катастроф. Это все устойчивые типы
переходов — прямой образ «7 взаимодействий» и узла 7.

| ADE | Катастрофа | codim | Нормальная форма |
|-----|------------|-------|------------------|
| A2 | складка (fold) | 1 | x³/3 + μx |
| A3 | **сборка (cusp)** | 2 | x⁴/4 + μ₂x²/2 + μ₁x |
| A4 | ласточкин хвост | 3 | x⁵/5 + … |
| A5 | бабочка | 4 | x⁶/6 + … |
| D4+ | гиперболическая омбилика | 3 | x₁³ + x₂³ − μ₃x₁x₂ − … |
| D4− | эллиптическая омбилика | 3 | x₁³ − 3x₁x₂² − … |
| D5 | параболическая омбилика | 4 | x₁⁴ + x₁x₂² + … |

4 куспоида (A-серия) + 3 омбилики (D-серия) = 7.

### Сборка = бифуркация модели `[✓]`

Бифуркация DIALOG QMT (φ-аттрактор ↔ нулевой аттрактор при μ_crit=0.5) — это
**катастрофа сборки**. Потенциал V(x)=x⁴/4+μ₂x²/2+μ₁x даёт:

- **бистабильность** (два аттрактора + скачок) внутри клина складок;
- **множество складок**: 4μ₂³ + 27μ₁² = 0;
- петлю гистерезиса (две устойчивые ветви) — `cusp_equilibria`, `cusp_is_bistable`.

Так «выбор траектории» в узле 5 (точка бифуркации) — это прохождение острия сборки.

## Пуанкаре: возврат `[✓]`

Теорема Пуанкаре о возврате: для преобразования, сохраняющего меру, почти всякая
точка бесконечно часто возвращается в окрестность начала. Это **цикл
S8→S9→S0→S1** (7-е взаимодействие, рекуррентное). В коде — золотой поворот
окружности x→(x+1/φ) mod 1: возврат в ε-окрестность за **n = 13 шагов** (число
Фибоначчи — лучшие приближения золотого поворота). `poincare_return_time`.

## Сахаров / CP: три условия асимметрии

Сахаров (1967): для перевеса вещества над антивеществом нужны три условия. Их
образ в DIALOG QMT (`sakharov_conditions`):

| Условие Сахарова | Образ в DIALOG QMT |
|------------------|--------------------|
| нарушение барионного числа | асимметрия узлов (не все пары точны) |
| нарушение C и **CP** | неточность зеркала −I — **смещение центра δ ≠ 0** |
| выход из равновесия | **немарковская память ε** (открытая система) |

δ = 0 ⇒ точное зеркало ⇒ мира нет. Смещение центра (флоу-слой) = CP-нарушение.

## Паули: запрет ⇒ различимость уровней `[✓]`

Принцип запрета Паули: нет двух тождественных состояний. Поэтому **4 уровня
памяти** (3 внутренних + внешний) различны — как 4 компоненты биспинора Дирака.
`pauli_distinct_levels`.
