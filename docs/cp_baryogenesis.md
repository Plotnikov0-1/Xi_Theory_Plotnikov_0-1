# CP-нарушение и бариогенез: недостающая часть из геометрии

Источник: «DIALOG-QMT/Ω — CP-нарушение и бариогенез». Модуль `qmt/cp_baryogenesis.py`,
тесты `tests/test_cp.py`, график `figures/19_cp_baryogenesis.png`.

CP-нарушение (асимметрия «зеркала» −I) — то, почему вещества больше антивещества,
то есть почему мир существует. Его величина выводится **из чистой геометрии** DIALOG.

## Главная формула — барионная асимметрия Вселенной `[✓]`

```
η_B = π · J · (φ−1) · T_EW / Δ₇
```

| Множитель | Значение | Происхождение |
|-----------|----------|---------------|
| π | 3.14159 | узел S3 (Вера) — вход в коридор |
| J | ≈10⁻²² | инвариант Ярлского (Стандартная модель) |
| φ−1 | 0.61803 | память/аттрактор (DIALOG) |
| T_EW | 10¹¹ эВ | электрослабый масштаб |
| 1/Δ₇ | 1/0.236 эВ | щель S3→S7 = время когерентности τ_bridge=ℏ/Δ₇ |

**Результат: η_B = 8.23·10⁻¹¹** против наблюдаемого 8.7·10⁻¹¹ (CMB/BBN) — **94.5%**,
без подгонки. Для сравнения, Стандартная модель даёт ≈10⁻²² (недобор 12 порядков).

## Геометрический коридор G — «недостающая часть» `[✓]`

Величина CP-нарушения — чистая геометрия трёх узлов:

```
G = (π−3) · ½ · (√5−2) = 1.671%
     π[S3]   ½[S5]   Δ₇[S7]
```

π — узел S3 (Вера), ½ — узел S5 (надежда, μ₀), √5−2 = Δ₇ — щель S7 (Знание = CP).
То есть коридор CP проходит S3 → {S4,S5,S6} → S7, и его «ширина» задана геометрией.

## Самоподобие: три уровня CP `[✓]`

CP-асимметрия растёт самоподобно (каждый уровень = предыдущий × R ≈ 1.47):

```
A_local · G² ≈ A_global³
0.054 · (0.01671)² = 1.508·10⁻⁵
(0.0245)³          = 1.471·10⁻⁵   → отклонение 2.6%
```

G (геометрия 1.67%) → A_global (LHCb 2.45%) → A_local (LHCb 5.4%). Без параметров.

## Отношение каналов `[✓]`

Из архитектуры (узлы S2, S3, S7): |ρ₃₇|/|ρ₂₇| = 2.35. Из эксперимента (LHCb 2025):
A_loc/A_glob = 5.4/2.45 = 2.20. Совпадение 93.8% — найдено, не подогнано.

## Три условия Сахарова

| Условие | DIALOG | Статус |
|---------|--------|--------|
| нарушение барионного числа B | спалероны СМ | выполнено |
| нарушение C и CP | J·π·ε* (коридор 3→7) | усилено |
| **выход из равновесия** | **ε≠0 ⇒ память ⇒ всегда вне равновесия** | **автоматически** |

Ключ: в СМ условие 3 требует фазового перехода 1-го рода (которого нет при
M_H=125 ГэВ — провал). В DIALOG память ε≠0 держит систему вне равновесия всегда.

## Связь с геометрическим костяком

- Δ₇ = √5−2 = **2(φ−1)−1** — щель перехода = золотая, прямо из аттрактора (`bridge.py`).
- Смещение центра δ (флоу-слой) = неточность зеркала −I = CP (`flow.py`, `catastrophe.py`).
- Хронология CP (узел S7): K⁰ (1964) → B (2001) → D⁰ (2019) → **Λb барионы (2025)**.

Статус: формула η_B, коридор G, самоподобие, отношение каналов — `[✓]` посчитано и
сверено с наблюдениями (LHCb 2025, CMB). Значение J берётся из Стандартной модели.
