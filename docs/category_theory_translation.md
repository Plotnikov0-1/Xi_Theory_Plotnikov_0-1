# Теория категорий как инструмент перевода аллегорий

Только структуры, формулы, примеры. Назначение: строгий язык, на котором
«одна и та же структура в разных языках» становится доказуемым утверждением.

---

## 1. Функтор и естественное преобразование

### Категория
Категория **C**: класс объектов Ob(C); для пары X,Y — множество стрелок
Hom(X,Y); композиция ∘ и единицы id, с аксиомами:

```
(h∘g)∘f = h∘(g∘f)            (ассоциативность)
id_Y ∘ f = f = f ∘ id_X      (единицы)
```

Объекты = «вещи», стрелки = «переходы/отношения». Структура категории — это
**закон композиции переходов**.

### Функтор (перевод одного языка в другой)
Функтор F: C → D сопоставляет объектам объекты, стрелкам стрелки, сохраняя
композицию:

```
F: Ob(C) → Ob(D)
F: Hom_C(X,Y) → Hom_D(FX,FY)
F(id_X) = id_{FX}
F(g ∘ f) = F(g) ∘ F(f)        ← КЛЮЧ: перевод сохраняет структуру переходов
```

Функтор — это и есть «перевод», при котором схема переходов не ломается.

### Естественное преобразование (перевод между переводами)
Для F,G: C → D естественное преобразование η: F ⇒ G — семейство стрелок
η_X: FX → GX, такое что для любой f: X→Y коммутирует **квадрат естественности**:

```
        F f
   FX ──────► FY
   │           │
 η_X│          │η_Y
   ▼           ▼
   GX ──────► GY
        G f

           η_Y ∘ F f = G f ∘ η_X
```

Если все η_X — изоморфизмы, η — **естественный изоморфизм**, F ≅ G.

### «Одинаковость структур» = эквивалентность категорий
C и D описывают одну структуру, если есть функторы F: C→D, G: D→C и
естественные изоморфизмы:

```
G∘F ≅ id_C ,    F∘G ≅ id_D
```

Эквивалентно: F **полный, точный, существенно сюръективный** (см. §4).

## 2. Одна структура переходов в физике, математике и символах

### Базовый объект: моноид/группа переходов
Моноид (M,·,e): ассоциативная операция с единицей. Один и тот же моноид
проявляется одновременно:

| Язык | Реализация | Операция |
|------|------------|----------|
| Физика | эволюция U(t)=e^{−iHt/ℏ} | U(s)U(t)=U(s+t) |
| Математика | (ℝ,+) | s+t |
| Символы | сдвиг/такт «время-шаг» | последовательность |

Это **функтор** из (ℝ,+) (категория с одним объектом) в группу унитарных
операторов:

```
Φ: (ℝ,+) → U(H),    Φ(t)=e^{−iHt/ℏ},    Φ(s+t)=Φ(s)Φ(t),  Φ(0)=I
```

Сложение времён ↔ композиция операторов — буквально одна структура.

### Экспонента как функтор
Для генератора A:

```
e^{(s+t)A} = e^{sA} e^{tA},   e^{0·A}=I
```

Функтор из аддитивного моноида (ℝ≥0,+) в моноид (End(V),∘). «Непрерывный
переход» = однопараметрическая полугруппа.

### Циклическая структура ℤ/n в трёх языках
Одна группа ℤ/nℤ:

| Язык | Реализация |
|------|------------|
| Геометрия | повороты на 2π/n (группа C_n) |
| Теория чисел | сложение по модулю n |
| Символы | 12 полутонов (ℤ/12), круг квинт; семья mod 3 (ℤ/3) |

Изоморфизм C_n ≅ ℤ/nℤ: поворот R_k ↦ k. Сохраняет композицию:
R_j R_k = R_{(j+k) mod n} ↦ (j+k) mod n.

### Марковские/квантовые переходы как категория
Объекты = состояния, стрелки = переходы с весами. Композиция = умножение
матриц переходов:

```
(P∘Q)_{ik} = Σ_j P_{ij} Q_{jk}
```

Закон Чепмена–Колмогорова P(s+t)=P(s)P(t) — это функториальность по времени
(та же §2-структура, что U(t)).

## 3. Теория групп как язык симметрий и переходов — платоновы тела

### Группа симметрии = инвариант формы
Группа вращений тела:

| Тело | Группа вращений | Порядок |
|------|-----------------|---------|
| тетраэдр | A₄ | 12 |
| куб / октаэдр | S₄ | 24 |
| додекаэдр / икосаэдр | A₅ | 60 |

Двойственные тела имеют **одну** группу: cube↔octahedron → S₄;
dodeca↔icosa → A₅. Двойственность — функтор, меняющий местами вершины и грани
(V↔F), сохраняющий группу.

### Представление = функтор G → Vect
Линейное представление группы:

```
ρ: G → GL(V),   ρ(gh)=ρ(g)ρ(h)
```

Это функтор из G (категория с одним объектом, стрелки = элементы) в векторные
пространства. Характеры χ(g)=tr ρ(g) — полный инвариант (для конечных групп
над ℂ).

### ADE / соответствие Маккея (строгий мост тел ↔ алгебра)
Конечные подгруппы SU(2) ↔ платоновы тела ↔ простые алгебры Ли (A,D,E) ↔
рациональные особости du Val. Для бинарных групп:

```
бинарный тетраэдр  ↔  E₆
бинарный октаэдр   ↔  E₇
бинарный икосаэдр  ↔  E₈
```

Механизм Маккея: неприводимые представления группы Γ⊂SU(2) ↔ узлы расширенной
диаграммы Дынкина; число рёбер = кратность в тензоре с фундаментальным
представлением. Это **доказанный** изоморфизм трёх «языков» (геометрия тел /
теория представлений / алгебры Ли).

## 4. Как строго доказывается структурный изоморфизм

Утверждение «два языка описывают одно» = **эквивалентность категорий**. Что
нужно показать для функтора F: C → D:

```
полнота:        F: Hom(X,Y) → Hom(FX,FY)  сюръективно
точность:       F: Hom(X,Y) → Hom(FX,FY)  инъективно
существ. сюръект: ∀ D∈Ob(D) ∃ C∈Ob(C): F(C) ≅ D
```

Полный + точный + существенно сюръективный ⇔ эквивалентность (есть обратный
G с G∘F≅id, F∘G≅id).

### Для алгебраических структур (частный случай)
Изоморфизм = биективный гомоморфизм φ, сохраняющий ВСЕ операции и отношения:

```
φ(x · y) = φ(x) ∗ φ(y)   для каждой операции
φ биективно
```

### Необходимые условия — инварианты
Функтор переводит инварианты в инварианты; если они не совпадают —
изоморфизма НЕТ (это и есть строгий способ ОПРОВЕРГНУТЬ ложный «перевод»):

```
|G| (порядок группы),  таблица характеров,
χ = V−E+F (эйлерова характеристика),
гомологии H_n,  спектр оператора,  размерность.
```

Совпадение всех релевантных инвариантов + явная биекция на hom-множествах =
доказательство.

## 5. Исторические случаи: метафора/аллегория → строгая теория

Механизм во всех — построить **функтор/двойственность** между языками.

| Год | Перевод | Механизм (формула) |
|-----|---------|--------------------|
| 1637 Декарт | геометрия ↔ алгебра | точка ↔ (x,y); кривая ↔ {f(x,y)=0} |
| 1832 Галуа | разрешимость ↔ группа | соответствие Галуа: подполя ↔ подгруппы |
| 1872 Клейн | геометрия ↔ (группа, действие) | геометрия = инварианты группы G |
| 1918 Нётер | симметрия ↔ закон сохранения | ∂L/∂q симметрия ⇒ dQ/dt=0 |
| 1936 Стоун | булевы алгебры ↔ топология | контравариантная эквивалентность |
| 1943 Гельфанд | C\*-алгебры ↔ компакты | A ≅ C(X), X=спектр |
| 1958 Гротендик | геометрия ↔ кольца | X ↦ Spec(R), функтор |
| 1958–69 Карри–Ховард–Ламбек | логика ↔ программы ↔ категории | доказательство = программа = стрелка |

### Соответствие Галуа (образец строгого «перевода»)
Между расширением полей K⊂L и группой G=Gal(L/K) — **обращающая порядок
биекция**:

```
H ⊆ G   ↦   L^H = {x : σx=x ∀σ∈H}     (неподвижное подполе)
K⊆E⊆L   ↦   Gal(L/E)
        E = L^{Gal(L/E)},   H = Gal(L/L^H)
```

Это галуа-связь (частный случай сопряжённости F ⊣ G): «решить уравнение» ↔
«разложить группу» — одна структура.

### Сопряжённость (адъюнкция) — общий механизм перевода
F ⊣ G (F левый сопряжённый к G) задаётся естественной биекцией:

```
Hom_D(F X, Y) ≅ Hom_C(X, G Y)     естественно по X,Y
```

Это формальное определение «двух взаимно-переводящих языков»: построение
свободной структуры F и забывающего функтора G. Любой строгий «перевод
аллегории» сводится к предъявлению такой пары (F,G) и проверке §4.

### Кэрри–Ховард–Ламбек (три языка = одна структура)
Точные изоморфизмы:

```
типы            ↔ высказывания      ↔ объекты ДКЗ-категории
программы (термы) ↔ доказательства   ↔ стрелки
A→B (функция)   ↔ A⇒B (импликация)  ↔ экспонента B^A
A×B             ↔ A∧B               ↔ произведение
```

(ДКЗ = декартово замкнутая категория.) Эталон того, что значит «три разных
языка описывают одну структуру» — доказано как изоморфизм категорий.

## Применение к программе DIALOG

Чтобы «перевод аллегории» был строгим (а не свободным сопоставлением), нужно
для каждой пары язык↔модель:

1. задать категории C (символический язык) и D (геометрия/физика);
2. предъявить функтор F: C→D (перевод объектов и переходов);
3. проверить §4 — совпадение инвариантов (|G|, χ=V−E+F, спектр) и биекцию на
   hom-множествах;
4. если инвариант не совпал — перевод опровергнут (это и есть фильтр против
   ложных совпадений из `coincidence_ledger`).

Каббала/буквы дают кандидатные функторы; их прочность проверяется §4 и осью
жёсткости из `synchronization.rigidity`. Доказанные мосты модели (двойственность
куб↔октаэдр, ADE, представление ρ:G→GL(V)) — уже эквивалентности категорий.
