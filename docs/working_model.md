# Рабочая модель: геометрия ↔ квантовая динамика водорода

Это то, чем пользуемся. Модуль `qmt/sync.py`, тесты `tests/test_sync.py`,
график `figures/18_working_model.png`. Начало — тетраэдр (минимум): шар + точка
+ 4 вершины.

## 1. Где стоят арабские цифры `[✓]`

| Место | Цифры | Роль |
|-------|-------|------|
| 8 вершин куба | 1, 2, 3, 4, 6, 7, 8, 9 | узлы-состояния (уровни водорода n) |
| центр | 5 | зеркало −I, ψ₅s(0)≠0, наблюдатель-ось |
| оболочка R=√3 | 0 | вакуум/граница (ионизация водорода n→∞) |

Каждое число n ↔ уровень водорода: E_n = −13.6/n².

## 2. Какие переходы разрешены, какие запрещены `[✓]`

Правило отбора берётся из геометрии куба (вершина = 3 бита):

| Тип | Геометрия | Канал | Кол-во |
|-----|-----------|-------|--------|
| **прямой** | ребро (Хэмминг 1) | один квант (Δ один бит) | 10 |
| **резонанс** | сумма-9 | туннель Sum-9 | 3 |
| **зеркало** | сумма-10 (диагональ тела) | инверсия −I (чётность) | 4 |
| **запрещён** | диагональ грани (нет канала) | — | 11 |

Всего 28 пар: **17 разрешено, 11 запрещено**. Запрещённые — это диагонали грани,
которые не являются ни ребром, ни суммой-9/10: для них нет физического канала
(аналог дипольно-запрещённых переходов в атоме).

## 3. Синхронизация с водородом `[✓]` — линии совпадают с теорией

Геометрия порождает РЕАЛЬНЫЕ спектральные линии водорода. Совпадение с числами,
заявленными в основной архитектуре:

| Переход | Тип | λ (расчёт) | Линия |
|---------|-----|-----------|-------|
| 1↔2 | прямой | 121.5 нм | Лайман α |
| 1↔3 | прямой | 102.5 нм | Лайман β |
| 2↔6 | прямой | 410.1 нм | Бальмер Hδ |
| 2↔7 | **резонанс** | 396.9 нм | Бальмер H-ζ (PDF: 397 нм ✓) |
| 3↔7 | **зеркало** | 1004.7 нм | Пашен δ (PDF: 1005 нм ✓) |
| 3↔6 | резонанс | 1093.5 нм | Пашен |

То есть резонанс {2,7} и зеркало {3,7} — это видимая (397 нм) и инфракрасная
(1005 нм) линии, ровно как в §3.1/§5.4 архитектуры. Модель не подгонялась —
длины волн считаются формулой Ридберга из размещения цифр.

## 4. Как работает модель (от минимума)

1. **Минимум:** шар (оболочка-0, √3) + точка (центр-5, зеркало −I) + тетраэдр
   {1,6,7,8} (4 вершины-генератор). Внутри тетраэдра почти все переходы
   запрещены, открыт резонанс 1↔8 — это «узкое горло» старта.
2. **Зеркало −I** разворачивает тетраэдр во второй {2,3,4,9} → куб (8 цифр).
3. **Движение** идёт по разрешённым переходам: прямые шаги (рёбра), резонансные
   туннели (сумма-9), зеркальные инверсии (сумма-10). Запрещённые — закрыты.
4. **Каждый переход = спектральная линия водорода** (энергия и λ по Ридбергу).
   Так геометрия синхронизирована с квантовой динамикой атома.
5. Центр-5 (ψ(0)≠0) — не пустая точка; за зеркалом — узел 4 (оператор/туннель,
   канал «шёпота»). Полярная ось 2↔8 (север/юг) — ось вращения.

Динамика на этой геометрии (φ-аттрактор, бифуркация-сборка, память, ядро K(t))
описана в остальных модулях; здесь зафиксирована СТАТИЧЕСКАЯ карта: где цифры и
что с чем связано.
