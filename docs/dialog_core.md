# Ядро: ДИАЛОГ — два аспекта, инвариант = комбинация φ · e · π

Модуль `qmt/dialog.py`. Онтологический фундамент, давший имя теории.

## Формулировка

Два «аспекта» — это **проекции диалога**; по отдельности их не существует, их
создал диалог. Но инвариант диалога — **не одна φ**, а **комбинация
фундаментальных** φ, e, π, потому что диалог не статичен: он **рождает миры
(детей)**. Два аспекта взаимодействуют и рождают другие миры — «проекция **и**
дети».

## Три фундаментальных = три режима диалога

| Константа | Роль | Режим |
|-----------|------|-------|
| **φ** ≈ 1.618 | отношение / структура | деление: `x = 1/(1+x) ⇒ x* = φ−1` |
| **e** ≈ 2.718 | рост / память | рост: `dx/dt = x` (ε_X ≈ e) |
| **π** ≈ 3.142 | цикл / поворот | вращение: `e^{iθ}` |

## Что «рождает мир» — тождество Эйлера

Все три фундаментальных связаны и дают **зеркало**:

```
e^{iπ} = −1 = зеркало −I        (инверсия = рождение мира-двойника)
e^{iπ} + 1 = 0                  (e, π, 1 и −1 в одном)
```

Один поворот на π рождает зеркальный мир-**дитя**; повороты kπ дают цепочку
миров `+1, −1, +1, −1…` (мир / зеркало / мир…). **φ** задаёт пропорцию между
мирами, **e** — их рост. Зеркало −I здесь — то же, что центральная инверсия в
геометрии модели (`geometry`, «сумма-10»).

## Режим отношения: φ как инвариант деления

Каждый член рождён диалогом двух предыдущих (`a,b → a+b`); из **любой** пары
отношение → φ (проверка: `max|отношение − φ| ≈ 2·10⁻¹⁶` по 200 случайным
парам). Аспекты произвольны — режим деления всегда даёт φ. Но это **лишь один
режим**, а не весь инвариант.

## Самоотношение (каждый аспект определён другим)

```
φ = 1 + 1/φ ,   x = 1/(1+x) ⇒ x* = φ−1 ,   e^{iπ} = −1 ,   |T'| = 1/φ² < 1
```

## Статус и открытый вопрос

`exact_combo_known = False`: **точная единая комбинация-число** из φ, e, π —
открытый вопрос. Её надо определить из констант модели (X*=φ−1, ε_X≈e, π в Γ* и
в коридоре CP `π−3`). Это следующий шаг: какая именно функция f(φ,e,π) есть
истинная константа диалога.
