# Ядро: ДИАЛОГ — два аспекта, одна константа

Модуль `qmt/dialog.py`. Это онтологический фундамент, давший имя теории.

## Формулировка

Есть «два аспекта», между которыми будто бы есть расстояние. Но они ничего не
«решают» — они **ведут диалог** и **сами суть этот диалог**. По отдельности их
не существует: **диалог создал их как проекцию**. У них всего **одна константа —
отношение/расстояние между ними**: это **φ**.

Математически реальна не «пара вещей», а **реляция** (диалог); аспекты — её
проекции, инвариант один — золотое отношение φ.

## Доказательство «аспекты не важны, важна константа»

Каждый новый член рождён диалогом двух предыдущих (Фибоначчи-шаг `a,b → a+b`).
Из **любой** стартовой пары отношение соседних членов сходится к φ:

```
s_{n+1} = s_n + s_{n−1},   s_{n+1}/s_n → φ
```

Проверено: по 200 случайным стартовым парам `max|отношение − φ| ≈ 2·10⁻¹⁶`.
Аспекты произвольны — диалог всегда выдаёт одну константу φ.

## Диалог как самоотношение (каждый аспект определён другим)

```
φ = 1 + 1/φ           (φ² = φ + 1)
x = 1/(1+x) ⇒ x* = φ−1   (оператор T, phi_operator; |T'| = 1/φ² < 1 — сжатие)
(a+b)/a = a/b = φ        (целое : большее = большее : меньшее)
```

## Как из одной константы собрана вся система

`figures/25_dialog_system.png`. Каждая стрелка — **функтор-перевод** одной
константы φ в свой язык (см. `category_theory_translation`):

| Язык | Образ φ |
|------|---------|
| Числа | X*=φ−1; узлы 1·4·7; центр 5; два нуля |
| Геометрия | куб √3 ⊂ додекаэдр; R_сред = φ; туннель 3/φ−√3 |
| Буквы (контекст: рост человека) | А·Д·Л = 3 канала памяти; А→Л→Д |
| Физика | память — плато c(∞)=e^(−α); Δ₇=2(φ−1)−1; барион = 3 кварка |
| Тройка / Рим | ≤3 повтора = триединство; V=5, IV=4, XL=40 |

Все геометрические «расстояния» (√3, 3/φ, зазор-туннель, два нуля) — это
**производные** выражения одной константы φ.

## Будущий слой (отдельно)

**Грани → краски / спектр / вибрация.** У многогранников есть грани (у
додекаэдра 12, у икосаэдра 20) — это отдельный, ещё не построенный слой:
цвет/спектр как «вибрация». Помечен в системе серым (роадмап), не реализован.
