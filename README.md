# DIALOG QMT — вычислительный фреймворк

**Quantum Memory Transition Theory (Теория квантовых переходов с памятью), v11.0**
Плотников Л.В., Харитонов Г.М.

Этот репозиторий — минимальный, но рабочий инструмент, который **считает,
проверяет и визуализирует** ключевые результаты теории DIALOG QMT.
Каждая формула из документа реализована в коде, а тесты проверяют, что
числа совпадают с архитектурным референсом.

> «Теория описывает переходы — не состояния. Топология (φ, e, π) определяет
> структуру. Динамика параметра памяти ε определяет наблюдаемую массу.»

## Геометрический фундамент — «не числа, а соотношения»

Костяк теории — **геометрия**, а не подогнанные десятичные числа. Из минимума
(точка + шар + один тетраэдр с живым центром-зеркалом −I) разворачиваются все
пять платоновых тел, а узлы несут **точные алгебраические соотношения**
(√2, √3, φ, π). Всё проверено **символьно** (`sympy`) — модуль `qmt/geometry.py`:

```
точка + шар(0) + тетраэдр
      │  зеркало −I в центре
      ▼
  два тетраэдра (звезда) → КУБ(8) ↔ ОКТАЭДР(6)      [мир √2/√3]
      │  + золотые точки (0,±1/φ,±φ) на той же сфере √3
      ▼
  ДОДЕКАЭДР(20) ↔ ИКОСАЭДР(12)                       [мир φ — пятикратность]
```

Доказано символьно `[✓]`: φ²=φ+1; Эйлер V−E+F=2 для всех 5 тел; куб и
додекаэдр на одной сфере R²=3; зеркало (сумма 10) = центральная инверсия −I;
резонанс (сумма 9); группа куба B₃=48, структура переходов D₁₀=20. Подробно —
[`docs/geometry.md`](docs/geometry.md).

## Установка (один раз)

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

## Как пользоваться

**1. Быстрая демонстрация всех расчётов** (числа в консоль):

```bash
python examples/quickstart.py
```

**2. Построить все графики** (сохранятся в папку `figures/`):

```bash
python visualize.py
```

**3. Проверить, что расчёты совпадают с документом:**

```bash
python tests/test_invariants.py
```

**4. Использовать как библиотеку** в своём коде:

```python
from qmt import constants as C
from qmt import dynamics, matrix6x6

print(C.X_STAR)                       # 0.6180339887  (φ-аттрактор)
print(dynamics.steady_state_load(0.5))  # = φ−1 при μ_crit=0.5
print(matrix6x6.spectral_invariants().trace)  # 9.0 (Sum-9)
```

1. **Спектральная плотность** J(ω) — суперомический резервуар.
2. **Уровни водорода** и узлы S0–S9 (φ-оптимальные выделены).
3. **Динамическая система** — эволюция X, ε, μ, τ.
4. **Бифуркация** — φ-аттрактор X*=φ−1 при μ_crit=0.5.
5. **Матрица 6×6** — спектр (Sum-9) и устойчивость к возмущению.
6. **Параметр искренности** S(ε) — теорема монотонности.
7. **Звезда (stella octangula)** — два тетраэдра в шаре-оболочке √3, центр-5 = зеркало.
8. **Мост φ** — куб ⊂ додекаэдр на одной сфере (пятикратность из золотых точек).
9. **φ через слои** — одно соотношение φ: геометрия → аттрактор → туннель → водород.
10. **Поток/трубка** — гладкая кривая (a=5,b=3) на сфере √3, центр со смещением.
11. **Трискелион** — 2D-проекция динамики (куб вдоль оси 1↔9), C₃, Горгона в центре.
12. **Серпинский-тетраэдр** — самоподобие (D=2) = уровни памяти.
13. **Синхронизация** — начинается с тетраэдра (K4), затем куб.
14. **Уровни памяти** — 3 внутренних + 1 внешний, связаны одновременно.
15. **Катастрофа сборки** — 7 катастроф Тома; бифуркация модели = сборка (cusp).
16. **Канал памяти 0→1/0→4/0→7** — семья 1,4,7 (mod 3), трещина 7→4→1.
17. **φ-оператор и ядро памяти** — T(x)→φ−1 и K(t) из C_eff (канон 2026).
18. **Рабочая модель** — цифры на кубе, разрешённые/запрещённые переходы, спектр водорода.
19. **CP / бариогенез** — η_B из геометрии (94.5%) и самоподобный рост CP-асимметрии.

## Что проверено расчётом (12 инвариантов)

Все 12 тестов воспроизводят числа документа: тождество a·ω=c; φ²=φ+1 ⇒ X*=φ−1;
τ_bridge=2.79 фс; λ₀=1.8, μ₀=0.5, Xc=3.6; Γ*=0.485; топология Sum-9 (5 пар,
сумма=9); симметрия матрицы 7×7; след матрицы 6×6 = 9; инвариант ритма ℛ≈0.21;
устойчивость φ-аттрактора; эталонные точки туннеля 0.1244/0.0775; монотонность S(ε).

## Статус и честные оговорки

Теория размечает каждое утверждение статусом Q0–Q4 (тождество → теорема →
следствие → гипотеза → соответствие источника). Фреймворк это сохраняет:

- **Точно по документу:** все константы, φ-аттрактор, Sum-9, спектр 6×6,
  эталонные точки туннеля.
- **Реализовано как модель/демонстрация** (где документ задаёт форму схематично):
  параметры ОДУ динамической системы, феноменологическая интерполяция
  прозрачности туннеля, модель декогеренции для параметра S. Эти места явно
  отмечены в docstring'ах и в `docs/overview.md`.
- **Не реализовано (задел на будущее):** ab-initio расчёт матричных элементов
  ⟨n|r̂|m⟩ водорода (используется значение из документа |ρ₃₇|/|ρ₂₇|=2.35);
  полное немарковское уравнение Накадзимы–Зваанзига; протокол IBM Quantum.
