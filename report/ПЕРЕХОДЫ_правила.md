# МАСТЕР-ТАБЛИЦА ПЕРЕХОДОВ И ПРАВИЛ (0→9, свод карт)

Сводит десять карт (0–9) в один путь: узлы, переходы между ними, правила отбора. Каждая строка
прослеживается до своей карты (проверено). Структурные догадки автора помечены статусом:
✅ проверено · 🟡 проверено средне (нужен ещё критерий) · 🔲 гипотеза (не канон).

## 2. ПЕРЕХОДЫ (рёбра пути) + ПРАВИЛА

| переход | что происходит | правило / физика | статус |
|---|---|---|---|
| **0→1** | рождение: первый разрыв симметрии | `Q\|0⟩=0 → ⟨φ⟩≠0`; â†; запись b:0→1 | ✅ |

**7→3** (Пашен Pa-δ, 1005 нм). Цвет = разность дробей 1/n².

## 3. СКВОЗНЫЕ НИТИ (проверено)

- **Декогеренция (γ):** 2 включает → 6 завершает → **7 обращает (рекогеренция)** → 9 финализирует + отрыв.
- **Память:** 0 хранит (ε, овал); 2 восстановима («вернуться»); 6 потеряна (в среду); **7 возвращена**
  (off-diag); 9→0 переносит ε (спираль). Sum-9-пара **2↔7** = «память цела».
- **Спираль:** цикл не замыкается — 9→0 сдвиг на ε (w+1). Часы = спираль из центра (`ЧАСЫ_СПИРАЛЬ`).

## 4. АНТИПОД / ДВЕ ВЕТВИ (рост + спад) — 🟡 проверено средне

- **Sum-9-инволюция** `P: i↦9−i`, `P²=I` (пары 0↔9,1↔8,2↔7,3↔6,4↔5). Проверено по стиху (средне-высокая):
  часть 1 = восходящая ветвь (1→9, **набор** памяти), часть 2 = нисходящая (**сброс**), P = антипод.
- Математика: P нечётна (det=−1, 5 транспозиций) = чётностный характер; ось при 4.5. Физика: C/P/T,
  L↔R в SO(4), две ветви гистерезиса. Инвариант: `i+P(i)=9`; знак `q=i−4.5` переворачивается.
- ⚠️ Нестыковка к развязке: **Sum-9** (ось 4.5) vs **Sum-10** (ось на 5, пик неподвижен) — какое где.

## 5. ЧИСЛОВОЙ ПОТОК (схема автора) — статусы

- **Вход 10,11,12 → 1,2,3 = mod 9** (`10≡1,11≡2,12≡3`, dr). ✅ (математика).
- **Выход вперёд 7,8,9 → 10,11,12 = +3** (спираль дальше); net к 1,2,3 по семьям mod 3. 🟡
- **Возврат 7,8,9 → 3,2,1** = отражение (Sum-10, ось 5). 🟡
- **Третий выход** = неустойчивый гребень cusp (кубика `x³+ux+v=0` даёт 3 корня: 2 устойчивых +
  1 неустойчивый = 5-пик, «скользко»). 🔲 гипотеза (физически мотивирована, не закреплена).

## 6. ГРАНИЦА УНИВЕРСАЛЬНОСТИ (кратко — отдельный документ следующим)

Числа 0–9 универсальны, пока держится **точный водород** (SO(4)/SO(4,2)) и **7 катастроф Тома**.
Ломается: тонкая структура (α²), лэмбовский сдвиг (1057 МГц), многоэлектронность, континуум/ионизация.

## ОТКЛОНЕНО (не канон, по правилу №1)
- Римский **сдвиг +1** (араб N = рим N→N+1) — проверка дала N≈N, отклонено.
- «6↔9 = зеркало» — на самом деле **поворот 180°** (R(π)); зеркало даёт ↄ, не 9.
- «40 = XL = разбитая чаша» — XL/40 в первоисточнике нет; разбитая чаша = C(100).
