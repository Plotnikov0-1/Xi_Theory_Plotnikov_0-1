## СЕМЬ СЛОЁВ КОНСТРУКЦИИ

### Слой 0 · КАРКАС — симметрия `◇✓` (+ ○)
**◇✓ Доказано:** φ — инвариант группы **\|G\|=120** (√5 в спектре икосаэдра, характер
A5 = (1±√5)/2). НЕ куб \|G\|=48 — спектр целый {−3,−1³,1³,3}, φ отсутствует.
**○ НЕ доказано:** «12-циферблат ⇒ G120» — дайл 2D (D12, \|G\|=24), додекаэдр 3D;
отождествление не выводится. φ-симметрия — абстрактный факт, привязка к часам ○.
→ `operator_algebra.golden_is_invariant_of_120_not_48`.

### Слой 1 · ДВА ОПЕРАТОРА (металлические средние) `◇✓`
Физически в зубьях шестерён:
- **φ золото = декагон** (10 зубьев): R/сторона = φ ровно;
- **√2 серебро = октагон** (8 зубьев): ширина/сторона = 1+√2 ровно.
Кольцо 40 = LCM(8,10). Универсальный переход **T(x)=1/(1+x)**, неподвижная точка φ−1.
→ `clock_gears`, `phi_operator`.

### Слой 2 · ТРИ СЕМЬИ = три квадрата `◇`
Z₁₂/⟨3⟩ ≅ Z₃, три смежных класса (квадраты 0/30/60°):
**π** {3,6,9,12} структура · **φ** {1,4,7,10} КАНАЛЫ (управляющий слой, несёт оператор,
не состояние) · **√2** {2,5,8,11} мембрана. 8 колёс замыкают 4·2+4·1 = 12 рёбер.
→ `clock_layers`.

### Слой 3 · ЦЕНТР — гармоничность `◇/✓` (+ ○)
**◇/✓ Доказано:** ∇²(1/r)=0 (гармонична) ⇒ устойчивой ямы в свободной точке нет
(теорема Ирншоу — ✓ установленная физика). **○ НЕ доказано:** «центр-5 = седло, выход
на узел 7» — интерпретация модели (у дискретного узла-5 нет своей динамики/потенциала).
→ `clock_geometry.center_is_saddle`, `node5`.

### Слой 4 · ЗАМЫКАНИЕ 12→13 `◇`
Каждая триада + свой двузначный ноль: {1,4,7}+10 · {2,5,8}+11 · {3,6,9}+12 (каждая ≅ Z₄).
13 ≡ 1 (mod 12) — ре-энтри (новая октава). Σ(1..12)=78=**6·13**. → `triad_zeros`.

### Слой 5 · ПРЕДСТАВЛЕНИЕ — плетёная сфера `◇✓` (+ ○)
**◇✓ Доказано:** гипоциклоида с R/r остриями: 10-колесо в кольце-40 → 4 остриё
(астроида), 8-колесо → 5 (5-лучевая). Золотой экватор sin72/sin36 = φ ровно.
Лифт Лиссажу на сферу точен для ЛЮБЫХ частот (Erb, arXiv:1802.06546).
**○ НЕ доказано (стресс-тест):** «нативная сфера 5:4» — сфера 5:4 НЕ построена
(`sphere_nodes` считает 5:3); 4 и 5 — числа остриёв ДВУХ разных кривых, не частоты
одной сферы; выбор «5:4 родная» не выведен. «4+5=9=Sum-9» — числовое созвучие (≈).
Шестерни ГРАВИРОВАНЫ и не вращаются → «передачи/гипоциклоиды» = мат. метафора, не физика.
→ `clock_gears.hypocycloid_cusps`, `sphere_nodes`, `report/sphere_of_eights.html`.

### Слой 6 · ЯДРО ДОКАЗАТЕЛЬСТВА `◇` (+ ○)
**◇ Доказано:** 2cos(2π/N) рационален только N∈{1,2,3,4,6}; **наибольший** такой N = 6.
Золотая точка x²+x−1=0. CP = R∘G (порядок 12). Все 7 шагов ядра проходят.
**○ Оговорка:** «теория ОБЯЗАНА взять N=6» — это постулат максимальности поверх
теоремы (сама даёт множество {3,4,6}). → `proof_core.all_steps_pass`.

## ВОДОРОДНЫЙ ЭТАЖ (был потерян — возвращён)

Настоящая физика водорода СИЛЬНЕЕ числовых совпадений, но выпала из хребта.
Возвращаю её отдельным этажом. Здесь ✓/◇ — реальная физика; ○ — наши отождествления.

**◇✓ Настоящие мосты (скрытая симметрия водорода):**
- **n² = точный квадрат** через SO(4): Казимир C₁=n²−1; гармоники S³ (ℓ+1)²; Σ(2ℓ+1).
  Четыре пути дают n². ◇ САМАЯ СИЛЬНАЯ связь. (`hydrogen_relations:n2_count`)
- **Чётность (−1)^ℓ → двудольность** графа переходов (Δℓ=±1, правило Лапорта). ◇✓
- **Рунге–Ленц ↔ зеркало**: A P-нечётен, L P-чётен = пара ±1 (= наш −I). ◇✓ / ○
- **Возврат/revival** T_rev = 2n/3·T_cl (возврат Пуанкаре); связанные состояния на
  компактной S³ (Фок 1935); [A,H]=0 ⇒ замкнутая орбита (Бертран). ✓
- **SO(4,2) dim=15** связывает весь спектр в один мультиплет. ✓
- **Стрела: спонтанный распад A∝ω³** (Эйнштейн 1917) = тот же ω³, что резервуар J(ω)∝ω³. ✓ / ○
- **Шёпот-канал 4↔6**: 0.472 эВ, 2624 нм, 5482 К — ЕДИНСТВЕННЫЙ «земной» переход. ✓
- **Температуры узлов** T_n (Больцман×Саха): рост к ионизации, бальмер-макс ~9000 К. ✓

**◇-тождества, которые НЕ физика (не спутать):**
- **Факторизация Ридберга**: ΔE=R·20(5−n)/(n²(10−n)²) [зеркало], R·9(9−2n)/(n²(9−n)²)
  [резонанс]. Проверено (656.1 нм Hα ✓). Но 20 и 9 — тривиальная разность квадратов
  (S−n)²−n²=S(S−2n); сумма выносится за скобку. Пары НЕ дипольные. ◇-алгебра, НЕ отбор.

**★ φ в водороде НЕТ** (ни уровни, ни Казимир, ни S³): φ — только геометрия G120.
Фибоначчи-радиусы r∝n²→φ² — отброшено как нумерология (`hydrogen_relations:null_results`).

**Единственный кандидат в новую физику:** 7→3/7→2 (см. P1 ниже).

## БРИФ ДЛЯ АГЕНТОВ (что запускать)

**Протокол честности (обязателен):** каждый вывод помечать ярусом ◇/✓/≈/○/★.
Не смешивать доказанное с интерпретацией. Совпадение ≠ подтверждение. Число вторично,
соотношение первично. Реальную физику/математику не выдумывать — брать установленную.

**Точка входа для проверки:** `python -m qmt.fundament` (весь хребет), полная
сборка тестов `tests/test_*.py` (все зелёные). Модуль + тест на каждую идею.

**Задачи для параллельных агентов (кандидаты):**
1. **Native-сфера 5:4** — построить сферу с частотами из передач (4,5), сравнить с
   кольцом восьмёрок на фото часов; посчитать узлы/самопересечения. (Слой 5)
2. **Ритм-верификатор** — сверить H10 (10-11-12/1-2-3) с реальными данными
   хронобиологии (мелатонин/кортизол), решить: ✓ или отбросить.
3. **Гео-аудит передач** — что даёт совместная работа 4:1 и 5:1 (две гипоциклоиды
   в одном кольце-40): суммарная фигура, симметрия, связь с 12-каркасом.
4. **Водородный опыт P1** — оформить точное предсказание 7→3/7→2 и условия
   ℓ-селективной накачки как готовый экспериментальный протокол.
5. **Критик полноты** — что в конструкции НЕ проверено? где ◇ выдаёт себя за ✓?
   найти дыры (напр. β=4/3 свободный параметр — см. `x_law`, `matrices_map`).

**Правило слияния:** агент доказал → модуль+тест, двигаем в фундамент. Опроверг →
в «Исправленные misread». Неясно → в HYPOTHESES с условием проверки.
