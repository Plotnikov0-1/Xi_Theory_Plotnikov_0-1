## 0. Фундамент — соотношение раньше числа

Две структурные истины, на которых стоит всё остальное.

**(а) Физика живёт в безразмерных соотношениях** (теорема Бакингема-Пи). Любой
закон сводится к тождеству `F(π₁,…,π_m)=0` между безразмерными π. Метр, секунда,
`c = 3·10⁸ м/с` — человеческие конвенции; инвариантна не переменная, а **π**.

**(б) Наблюдаемое рождается как самопроизведение.** Амплитуда `ψ` — комплексная,
ненаблюдаемая. Наблюдаемое появляется только через **замыкание на сопряжённую
себе**:
```
P = ψ·ψ* = |ψ|²        (правило Борна)
```
Это ядро целого семейства: `A=πr²`, `E=½mv²`, `E=mc²`, `|F|²` (Фурье),
`ds²=c²dt²−dx²`, теорема Пифагора, `1/r²` (Ньютон, Кулон). Везде — **связь,
замкнутая на себя**. Квадрат — подпись разделения: чтобы единое проявилось, оно
проходит через себя и оставляет след. Первая степень (Ом, `F=ma`) — это передача,
а не рождение.

**Главное безразмерное число фундамента** ✓
```
α = e²/(4πε₀ℏc) = 1/137.035999     (отклонение от CODATA: 0 ppm)
```
Вот откуда настоящее «137» — из самозамыкания заряда, а не из геометрии.
(Золотой угол 137.5° — отдельное численное совпадение, 0.34%, связи нет.)

## 1. Атом водорода — базис и измерительная линейка

Водород выбран не случайно: это единственный атом с **точным** аналитическим
решением. Он — наша линейка.

**Уровни** ✓
```
E_n = − R_H·h·c / n²          R_H = R∞·m_p/(m_p+m_e)  (приведённая масса)
```

**Спектр** — сверено с NIST Atomic Spectra Database (вакуум):

| Серия | Переходы | Отклонение от NIST |
|---|---|---|
| Лайман (→1) | Lyα, Lyβ, Lyγ | 0.2–0.4 ppm |
| Бальмер (→2) | Hα, Hβ, Hγ, Hδ | **0.0 ppm** |
| Пашен (→3) | Paα, Paβ | 0.2 ppm |

**Безразмерное содержание водорода** ✓
```
E_связи(H) / (m_e c²) = α²/2          (формула Зоммерфельда; 0.05%)
```
Энергия связи атома — это `α²/2` доля энергии покоя электрона. Снова **только
соотношение**, без единиц.

> Честно: совпадение 0.0 ppm — **не заслуга модели**, а проверка корректности кода.
> Это стандартная квантовая механика (формула Ридберга). Модель **корректно
> использует** водород как базис — не более и не менее.

## 2. Симметрия и вырождение

Невозмущённый водород `H₀ = p²/2m − e²/4πε₀r` имеет симметрию **SO(3)**.
Следствие — **вырождение по m**:
```
E_{n,l,m} = E_{n,l}        (энергия не зависит от проекции m = −l,…,+l)
```
Все m-состояния при заданном (n,l) имеют одну энергию. Это «зеркальная решётка» на
сфере: `m` и `−m` неразличимы.

**Дискретный образ этой структуры** ◇ — три независимых 3-цикла
(1-4-7 / 2-5-8 / 3-6-9) как оператор перестановки `P` (9×9). Точно:
```
σ(P) = {1, ω, ω²},   ω = e^{2πi/3},   каждое ×3,   P³ = I
Π = (I + P + P²)/3    — проектор на наблюдаемое (λ=1) подпространство
```
`λ=1` — устойчивое наблюдаемое (вектор (1,1,1)); `ω, ω²` — скрытые фазовые моды
(векторы (1,ω,ω²), (1,ω²,ω)). Это точная линейная алгебра.

## 3. Неточное зеркало — CP-нарушение

Операция CP отображает `m → −m`. **CP-симметрия ⟺ `E_m = E_{−m}`.** Нарушение —
это наклон спектра:
```
CP-нарушение  ⟺  E_m ≠ E_{−m}
```
Любое возмущение, **нечётное по m**, снимает вырождение и ломает зеркало. Полное
разложение спектра: чётная часть (CP-сохраняющая) + **все нечётные мультиполи**
`m¹, m³, m⁵…` (это все каналы CP). Для спина `l` каналов ровно `l`; триада `l=1`
(m=−1,0,+1) → **ровно 1 канал**.

**Жёсткий результат — CP требует ровно трёх поколений** ✓ (Кобаяши-Маскава, Нобель
2008). Число физических CP-фаз матрицы смешивания:
```
n_фаз(N) = (N−1)(N−2)/2        N=1→0,  N=2→0,  N=3→1
```
При двух поколениях CP **невозможно**. Нужно **три** — и тогда возникает **ровно
одна** CP-фаза. Триада l=1 (3 состояния → 1 CP-канал) повторяет эту структуру «3→1».

**Экспериментальные якоря:**
- ✓ линейное расщепление m = **эффект Зеемана**, `ΔE = μ_B·B·m` (μ_B = 5.79·10⁻⁵
  эВ/Тл) — реально и измерено;
- ✓ мера CP в Стандартной модели — **инвариант Ярлског** `J = 3.08·10⁻⁵` (PDG);
- ○ внутреннее CP без внешнего поля = постоянный **ЭДМ электрона**; эксперимент:
  `|d_e| < 4.1·10⁻³⁰ e·см` (JILA 2023) — то есть внутреннее CP **≈ 0**.

## 4. Космология — почему вообще есть вещество

Здесь линия из атома выходит во Вселенную. **Условия Сахарова (1967)** для
возникновения преобладания вещества над антивеществом (бариогенезис):

1. нарушение барионного числа B;
2. нарушение C и **CP**;
3. отход от теплового равновесия.

Второе условие — это **в точности** неточное зеркало из §3. Физический смысл
строгий, не метафора: **будь зеркало точным (CP сохраняется) — вещество и
антивещество аннигилировали бы полностью, осталась бы пустота.** Существование
проявленного мира требует, чтобы зеркало было неточным. CP-нарушение — **не
дефект, а условие бытия**.

**Наблюдаемая барионная асимметрия** ✓ (Planck/BBN):
```
η_B = n_B/n_γ ≈ 6.1·10⁻¹⁰
```

**И здесь — честная граница физики** ✗. Известного CP-нарушения Стандартной модели
(того самого `J`) **не хватает на ~9 порядков**, чтобы объяснить наблюдаемую η_B:
```
η_B (оценка из CP СМ) ~ 10⁻¹⁸     против     η_B (наблюдаемая) ≈ 6·10⁻¹⁰
```
Это **реальная нерешённая проблема** современной физики (нужно CP-нарушение за
пределами Стандартной модели). Линия разворачивания приводит ровно к одной из
настоящих границ знания — и честно на ней останавливается.

## Единая нить

Сквозь все пять уровней проходит **одна структура**:

> **Проявленное = носитель × связь, замкнутая сама на себя.**
> А зеркало этой связи **неточно** — и именно поэтому мир существует, а не
> схлопывается обратно в симметрию.

| Уровень | Связь, замкнутая на себя | Неточность зеркала |
|---|---|---|
| Фундамент | `ψ·ψ*` (Борн), `α=e²/ℏc` | — |
| Водород | `E∝1/n²`, `α²/2` | — |
| Симметрия | `P³=I`, `Π=(I+P+P²)/3` | вырождение по m |
| CP | нечётные мультиполи `m^(2k+1)` | `E_m ≠ E_{−m}` |
| Космология | Сахаров: C, CP, неравновесие | η_B ≈ 6·10⁻¹⁰ |

## Что подтверждено, что открыто (без иллюзий)

- ✓ **Подтверждено экспериментом:** спектр водорода (ppm), `α=1/137` из `e²/ℏc`,
  `α²/2`, эффект Зеемана, Ярлског `J`, η_B, **CP требует 3 поколений**, предел ЭДМ.
- ◇ **Точная математика:** спектр `{1,ω,ω²}`, проектор `Π`, разложение CP-каналов,
  масштабная точка `x*=φ−1`.
- ○ **Модель / аналогия:** что три 3-цикла *суть* три поколения — структурное
  соответствие, не доказательство; `φ`-константы (`Γ*`, `Ω_D`) — внутренние.
- ✗ **Открытая проблема (общая для всей физики):** количественный бариогенезис —
  CP Стандартной модели мало на ~9 порядков.
- ✗ **Убрано как фон:** «137 из золотого сечения», `Δ₇=√5−2` как зазор уровней,
  гравитация через вибрацию / эфир — без оснований.

симметрию и неточное зеркало — к космологическому вопросу, почему есть вещество. На
каждом шаге — либо проверенная физика, либо честно отмеченная граница. Это не
«теория всего». Это **карта одной структуры — неточного зеркала — на всех
масштабах, от атома до Вселенной.**
