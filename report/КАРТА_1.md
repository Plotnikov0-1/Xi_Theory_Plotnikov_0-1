## 3. ОПЕРАТОР Op₁

- **Имя:** Рождение / Импульс / главное квантовое число n.
- **Определение:** оператор, порождающий первое возбуждение из вакуума и задающий **необратимую метку
  события** (b=1); несёт направление (вектор) и число n.
- **Операторная форма:** **â†** (бозоны: â†\|n⟩=√(n+1)\|n+1⟩, â†\|0⟩=\|1⟩; фермионы: (â†)²=0, Паули).
  Метка события: b=T(M(\|ψ⟩))=1 (необратимая запись). Направление: ⟨φ⟩≠0 / единичный вектор n̂.
- **Действие:** переводит 0→1 (рождение), поднимает уровень (a†), фиксирует одну ветвь (запись).

## 4. ФИЗИКА — ДОКАЗАННОЕ (со ссылками)

**Оператор рождения:**
- CCR `[â,â†]=1`, число `N=â†â` (спектр 0,1,2…), `â†|n⟩=√(n+1)|n+1⟩`, `â†|0⟩=|1⟩`, `|n⟩=(â†)ⁿ/√(n!)|0⟩`
  (Dirac §34; Sakurai–Napolitano §2.3). Пространство Фока (Fock, Z. Phys. 75, 622 (1932),
  DOI:10.1007/BF01344458). Фермионы: `{â_i,â†_j}=δ_ij`, `(â†)²=0` = **Паули** (Jordan–Wigner, Z. Phys.
  47, 631 (1928), DOI:10.1007/BF01331938). `[ДОКАЗАНО]`
- Рождение реальных фотонов из вакуума — динамический Казимир (Wilson et al., Nature 479, 376 (2011),
  arXiv:1105.4714). `[ДОКАЗАНО, наблюдено]`

**n=1 и серия Лаймана:**
- `E_n=−Ry/n²`, `E_1=−13.6057 эВ` (Ry=13.6057 эВ, CODATA; приведённая масса → 13.5984 эВ для H). 1s
  волновая функция без узлов: `ψ_100=(1/√π)a₀^{−3/2}e^{−r/a₀}`. `[ДОКАЗАНО]` (Griffiths §4.2; NIST).
- **Серия Лаймана** (переходы на n=1, УФ): Лайман-α (2→1) λ=121.567 нм, E=10.199 эВ; предел 91.18 нм
  (Lyman, ApJ 23, 181 (1906); NIST ASD). Согласуется с картой 0: n→1 = УФ = невидимо («0/1 чёрные»).
- Вырождение `Σ(2ℓ+1)=n²` из **SO(4)** (вектор Лапласа–Рунге–Ленца) — Pauli, Z. Phys. 36, 336 (1926);
  Fock, Z. Phys. 98, 145 (1935); Bander–Itzykson, RMP 38, 330 (1966). `[ДОКАЗАНО]`

**Стрела / необратимость (это отдельный слой — важно, см. поле 5):**
- Прямое **T-нарушение**: BaBar, PRL 109, 211801 (2012), arXiv:1207.5832 (14σ); CPLEAR, Phys. Lett. B
  444, 43 (1998). CP: Christenson–Cronin–Fitch–Turlay, PRL 13, 138 (1964). **CPT-теорема** (Lüders–
  Pauli; Streater–Wightman 1964): CP-наруш. ⇔ T-наруш. `[ДОКАЗАНО]`
- Термодинамическая стрела: `dS≥0`; H-теорема (Boltzmann 1872, с оговоркой Лошмидта — из обратимой
  динамики 2-е начало не выводится без Stosszahlansatz). **Ландауэр** `Q≥k_BT ln2` (IBM 1961; измерено
  Bérut, Nature 484, 187 (2012)). Ярзинский PRL 78, 2690 (1997); Крукс PRE 60, 2721 (1999). `[ДОКАЗАНО]`
- **Необратимость записи** = декогеренция/einselection: `ρ_ij(t)=ρ_ij(0)⟨ε_i(t)|ε_j(t)⟩~e^{−t/τ_D}`
  (Zurek, RMP 75, 715 (2003), arXiv:quant-ph/0105127). `[ДОКАЗАНО]` (единственность исхода —
  интерпретационно).

**«Пластилин» = восприимчивость:**
- Линейный отклик Кубо `χ_AB(t)=(i/ℏ)θ(t)⟨[A(t),B(0)]⟩` (Kubo, JPSJ 12, 570 (1957)); ФДТ Callen–Welton
  (Phys. Rev. 83, 34 (1951)); `χ_T=Var(M)/(k_BT V)`. Дивергенция у критической точки `χ∝|t|^{−γ}`,
  γ≈1.237 (3D Ising, arXiv:1603.04436). Хаос: `|δZ(t)|≈|δZ(0)|e^{λt}` (Lorenz, JAS 20, 130 (1963)). `[ДОКАЗАНО]`

**Рождение = затрата энергии + обратная реакция:**
- `ΔE=ℏω=hν` (Planck 1901; Einstein 1905). Лармор `P=q²a²/(6πε₀c³)`; сила Абрахама–Лоренца
  `F_rad=mτ₀ȧ` (Jackson §16.2; Dirac, Proc. R. Soc. A 167, 148 (1938)). Отдача источника (Мёссбауэр):
  `E_отдачи=(ℏω)²/(2Mc²)` — **измерено**. Швингер: рождение пар `E_c=m_e²c³/(eℏ)≈1.32×10¹⁸ В/м`
  (Schwinger, Phys. Rev. 82, 664 (1951)); порог пары `2m_ec²=1.022 МэВ`. `[ДОКАЗАНО]`

**Единица = вектор:**
- Единичный вектор `n̂=v/‖v‖`, `S^{n−1}`. p-орбитали (l=1) `Y_1^m` преобразуются как компоненты
  **вектора**, **нечётная чётность** `P Y_l^m=(−1)^l`. Дипольное правило `Δl=±1, Δm=0,±1` (Вигнер–
  Эккарт/Лапорт). Вектор = **j=1** непривод. представление SO(3). ⟨φ⟩≠0 при SSB выделяет направление
  (Goldstone–Salam–Weinberg 1962). `[ДОКАЗАНО]`

## 5. ФИЗИКА — ИЗ АЛЛЕГОРИИ, ещё НЕ доказанное (сохраняем!)

`[ИЗ АЛЛЕГОРИИ]` — держим как проверяемые гипотезы; несколько тезисов скептик **отбросил** — не тащим:

- **«Стрела бьёт только вас» = единая фундаментальная стрела времени.** Осторожно: физика даёт
  НЕСКОЛЬКО стрел (термодинамическую, космологическую, T-нарушение), а их совпадение объясняется
  **гипотезой низкой начальной энтропии** (Past Hypothesis / Вейль-кривизна Пенроуза), НЕ выводится из
  динамики. Проверяемо: связать термо- и космо-стрелу через начальную энтропию.
- **Разделение двух «стрел» числа 1 (уточнение модели):** «стрела» = (а) **пространственный вектор**
  (⟨φ⟩, l=1, ⟨φ⟩-ось) — `[ДОКАЗАНО]`; и (б) **необратимость записи** (декогеренция+Ландауэр) —
  `[ДОКАЗАНО]`; но НЕ фундаментальная **временна́я** стрела (это Past Hypothesis). Отождествлять их —
  `[ИЗ АЛЛЕГОРИИ]`, держим раздельно.
- **Рождение = критическая точка с расходящейся χ** (мягкий «пластилин» по определению). Проверяемо:
  отклик формирующихся систем (морфогенез, порог лазера) `χ∝|t−t_start|^{−γ}`. Не универсально
  (бывают гладкие/1-го рода старты).
- **Объективный коллапс** (GRW/CSL, Диóси–Пенроуз): необратимость измерения как реальная редукция.
  Проверяемо: спонтанное нагревание (ограничения Гран-Сассо), `τ~ℏ/E_G` на массивных интерферометрах.
- **«Боль матери = отдать силы»** — имеет **доказанное ядро**: отдача при испускании (Мёссбауэр). `[ДОКАЗАНО-ядро]`
- **Космическая ось из SSB** (⟨φ⟩ задаёт выделенное направление Вселенной): проверяемо, но
  **не в пользу** — Planck 2018 находит статистическую изотропию («ось зла» лишь ~2–3σ).

**Отброшено скептиком (не тащим дальше):**
- ✗ «Непокорный сын уничтожает мать» = back-reaction разрушает источник (runaway). Артефакт точечной
  модели; устраняется уравнением Ландау–Лифшица; реальный источник не саморазрушается.
- ✗ «Среда-мать/эфир отдаёт энергию» — эфир опровергнут (Майкельсон–Морли 1887); корректно — квантовое
  поле/вакуум.
- ✗ «1 = стрела времени» буквально — категориальная ошибка: вектор (пространство/поле) ≠ время.
- ✗ «Единица онтологически — вектор» — скаляр 1 (ранг 0) ≠ единичный вектор (ранг 1) под SO(3).

## 6. ВОДОРОД / КВАНТОВОЕ ЧИСЛО

- **1 = главное число n** (генератор энергии/радиуса). Проявление — **дробь** `E∝1/n²`, `r_n=n²a₀`
  (само целое n не наблюдаемо, см. `ЦЕЛОЕ_И_ДРОБЬ.md`).
- n=1 = 1s: без узлов, сферическое, минимальный радиус a₀. Переходы n→1 = **Лайман (УФ, невидимо)** —
  «1 ещё чёрная/невидимая», цвет включится с n=3 (см. карту 0 и `ЧИСЛА_НА_ВОДОРОД.md`).

## 7. ПЕРЕХОДЫ И ПРАВИЛА

- **0→1 (рождение):** первый разрыв симметрии `Q|0⟩=0 → ⟨φ⟩≠0`; `â†|0⟩=|1⟩`; запись `b:0→1`
  (необратимо). Нужен открытый канал (буква А), иначе перехода нет.
- **1→2 (подъём):** поглощение, `â†` ещё раз; далее по лестнице. Дипольное правило на ℓ: **Δℓ=±1,
  Δm=0,±1** (Вигнер–Эккарт). Само n меняется поглощением/испусканием фотона.
- **Правило необратимости:** после `b=1` событие записано — обратного преобразования нет (стрела
  записи). Это НЕ то же, что фундаментальная стрела времени (см. поле 5).

## 8. ГРАНИЦА УНИВЕРСАЛЬНОСТИ

- n универсально для **водородоподобных (1/r)** систем (симметрия SO(4), вырождение n²).
- **Где ломается:** любое отклонение от точного 1/r снимает вырождение — **тонкая структура** (α²),
  **лэмбовский сдвиг** (2s₁/₂–2p₁/₂ ≈ 1057 МГц), Штарк/Зееман. Значит «универсальность n» —
  динамическая/приближённая. Сюда (тонкая структура, КЭД-петли) — «многообразие, куда на уровне
  фундамента не лезем».
- Также вне фундамента: происхождение космологической стрелы времени (Past Hypothesis).

## 9. ЭКСПЕРИМЕНТ / ПРОВЕРКА

- **Рождение реально:** динамический Казимир (Wilson 2011); рождение пар (порог 1.022 МэВ, измерено).
- **Необратимость реальна:** Ландауэр (Bérut 2012), Крукс (Collin 2005), T-нарушение (BaBar 2012).
- **Отдача реальна:** Мёссбауэр.
- **Открытые предсказания модели:** объективный коллапс (CSL/Диóси–Пенроуз); χ∝|t−t_start|^{−γ} у старта.
