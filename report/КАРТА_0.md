## 3. ОПЕРАТОР Op₀

- **Имя:** Источник / Вакуум / Память.
- **Определение:** нейтральный элемент цикла — состояние без принятого события (b=0), несущее память ε.
- **Операторная форма:** тождество/проектор на вакуум. U(0)=e⁰=I (нет эволюции за нулевое время);
  â\|0⟩=0, N\|0⟩=0 (нет квантов); Q\|0⟩=0 (несломанная симметрия). Носитель памяти: ε=√(1−Tr ρ²).
- **Действие:** ничего не порождает сам по себе (генератор «за миром»); задаёт начало отсчёта и
  хранит след предыдущего витка (ε₀≠0). Проявляется только дробью (E∝1/n²), см. `ЦЕЛОЕ_И_ДРОБЬ.md`.

## 4. ФИЗИКА — ДОКАЗАННОЕ (со ссылками)

**Вакуум и нулевые колебания ½ℏω:**
- Основное состояние осциллятора: `Ĥ=ℏω(â†â+½)`, `â|0⟩=0`, `E₀=½ℏω` (не ноль!). `[ДОКАЗАНО]` —
  Landau–Lifshitz QM §23; Sakurai гл.2. Вынуждено `[x̂,p̂]=iℏ`: `Δx·Δp≥ℏ/2` даёт минимум ровно ½ℏω
  (Heisenberg, Z. Phys. 43, 172 (1927), DOI:10.1007/BF01397280).
- КТП: `E_vac=Σ_k ½ℏω_k` (расходится, регуляризуется). Peskin–Schroeder §2.3; Milton, *The Casimir
  Effect*, arXiv:hep-th/9901011 (исходный агент дал ошибочный id, скептик исправил).
- **Эффект Казимира** — экспериментальное подтверждение модифицируемой границами энергии вакуума:
  `F/A=−π²ℏc/(240a⁴)` (Casimir 1948, Proc. K. Ned. Akad. Wet. B51, 793). Измерено: Lamoreaux, PRL 78,
  5 (1997), DOI:10.1103/PhysRevLett.78.5 (~5%); Mohideen–Roy, PRL 81, 4549 (1998),
  arXiv:physics/9805038 (~1%). **Динамический Казимир** — рождение фотонных пар из вакуума: Wilson et
  al., Nature 479, 376 (2011), DOI:10.1038/nature10561. `[ДОКАЗАНО, наблюдено]`

**Ноль как единица / несломанная симметрия:**
- Аддитивный нейтральный элемент единствен; `exp(0)=1`; `exp(0·X)=I` (Hall, *Lie Groups*, Springer GTM
  222, DOI:10.1007/978-3-319-13467-3). `U(0)=e⁰=I` (теорема Стоуна; Reed–Simon vol. I). `[ДОКАЗАНО]`
- Несломанная симметрия ⇔ `Q|0⟩=0` (⇔ `e^{iαQ}|0⟩=|0⟩`); при `Q|0⟩≠0` — спонтанное нарушение и
  голдстоуновские бозоны (Goldstone–Salam–Weinberg, Phys. Rev. 127, 965 (1962),
  DOI:10.1103/PhysRev.127.965). Строгая оговорка: Fabri–Picasso (Q на \|0⟩ не определён при SSB). `[ДОКАЗАНО]`

**Овал = снятие вырождения (SSB / «мексиканская шляпа»):**
- `V(φ)=λ(|φ|²−v²/2)²`: кольцо вырожденных минимумов (окружность в пространстве поля). Теорема
  Голдстоуна: `N_Goldstone=dim G−dim H` (U(1)→1 мода). Радиальная мода массивна, угловая безмассова.
  Goldstone, Nuovo Cim. 19, 154 (1961); Nambu–Jona-Lasinio, Phys. Rev. 122, 345 (1961). `[ДОКАЗАНО]`
- **Явное** нарушение (наклон/овальность) → псевдо-голдстоун с массой `m²∝ε` (GMOR, Phys. Rev. 175,
  2195 (1968)). Ландау: `F=a(T)|ψ|²+b|ψ|⁴`, `|ψ|₀∝(T_c−T)^{1/2}`. `[ДОКАЗАНО]`
- Геометрия эллипса: `e=c/a=√(1−b²/a²)`, `e=0⇔круг` (фокусы сливаются, SO(2)). `[ДОКАЗАНО, тождество]`

**Память / чистота / немарковость:**
- Чистота `μ=Tr(ρ²)=Σλ_k²`, `1/d≤μ≤1`; линейная энтропия `S_L=1−Tr(ρ²)` (Nielsen–Chuang §2.4;
  Breuer–Petruccione гл.2). Кубит: `Tr(ρ²)=(1+|r|²)/2`. `ε=√(1−Trρ²)=√S_L`, `ε=0⇔чистое`. `[ДОКАЗАНО, тождество]`
- Немарковость (память среды): BLP — рост следовой дистанции `σ(t)=dD/dt>0` = возврат информации
  (Breuer–Laine–Piilo, PRL 103, 210401 (2009), arXiv:0908.0238); RHP — нарушение CP-делимости (Rivas–
  Huelga–Plenio, PRL 105, 050403 (2010), arXiv:0911.4270). Обзор: Rev. Mod. Phys. 88, 021002 (2016). `[ДОКАЗАНО]`

**Фаза Берри = геометрический след цикла (память формы пути):**
- `γ_n(C)=i∮⟨n|∇_R|n⟩·dR` — зависит от геометрии, не от скорости (Berry, Proc. R. Soc. A 392, 45
  (1984), DOI:10.1098/rspa.1984.0023; Simon, PRL 51, 2167 (1983)). Спин: `γ=−m·Ω(C)`, спин-½ при
  Ω=2π ⇒ `e^{iγ}=−1`. **Эксперимент:** Tomita–Chiao, PRL 57, 937 (1986) (поворот поляризации в
  спиральном волокне). Неадиабатически: Aharonov–Anandan, PRL 58, 1593 (1987). `[ДОКАЗАНО, наблюдено]`

**Кеплер — один фокус занят, второй пуст:**
- Орбита — эллипс, масса в **одном** фокусе, `E=−GMm/(2a)<0`; форму несёт вектор Лапласа–Рунге–Ленца
  `|A|=GMm²·e` (сохраняется). `[ДОКАЗАНО]`

## 5. ФИЗИКА — ИЗ АЛЛЕГОРИИ, ещё НЕ доказанное (сохраняем!)

`[ИЗ АЛЛЕГОРИИ]` — держим как проверяемые гипотезы модели, не выбрасываем:

- **«Вакуум хранит память об истории».** Станд. КТП: \|0⟩ инвариантен, памяти не несёт. Проверяемо:
  гистерезис вакуумного шума (СКВИД-резонатор) от предыстории границ при фиксированной геометрии;
  предсказание станд. физики — 0. *Модель предсказывает ≠0.*
- **«Два фокуса = прошлое и будущее (память)».** Не теорема. Строгая переформулировка: память ⇔
  немарковское ядро `K(t−t')` с **двухполюсной** структурой `K(ω)` (два полюса ↔ два фокуса).
  Проверяемо через автокорреляцию/ядро памяти; сверка интервалов BLP-backflow с «эксцентриситетом»
  образа шара Блоха.
- **«ε=√(1−Trρ²) = число 0» как параметр порядка** перехода чистота→смесь с показателем `ε∼|g−g_c|^β`.
  Каветат скептика: обычная декогеренция даёт ε **аналитичным** по g (нет настоящего перехода);
  фальсифицируется аналитичностью ε(g). ε — мера смешанности/параметр порядка, **не** сертифиц.
  мера немарковости (может расти под CP-делимой картой).
- **«Овал = деформация тела».** Точнее: реальный эксцентриситет = **явное** нарушение (наклон шляпы),
  щель угловой моды `ω²∝(эллиптичность)→0` при e→0 (мягкая мода; БЭК, метаматериалы). *Проверяемо.*
- **«Фаза не обнуляется ⇒ спираль, не круг».** Строго: луч состояния возвращается в круг, но в слое
  U(1) траектория смещена на γ(C) — геликоид; N циклов → накопление Nγ(C) (сдвиг полос ∝ N). Это
  **доказуемая** часть «спирали»; «память как произвольная информация» — нет (фаза несёт одно число).
- **«½ℏω — резервуар энергии».** `[ОТБРОШЕНО скептиком]` — минимум энергии, не резервуар; вечный
  ZPE-двигатель нарушил бы 2-е начало. Оставляем как **опровергнутую** гипотезу (не тащим дальше).

## 6. ВОДОРОД / КВАНТОВОЕ ЧИСЛО

- 0 — **до** главного числа n; это не уровень, а **референс/вакуум** и единица группы.
- Проявление — только дробь: `E_n=−Ry·(1/n²)` (само целое n не наблюдаемо, см. `ЦЕЛОЕ_И_ДРОБЬ.md`).
- 0 = основное состояние-минимум (s-симметрия, сфера), но «идеал круг» недостижим: остаётся ½ℏω
  (овал≠круг). Спектроскопически 0 = чёрный/вне видимого (переходы n→1 Лаймана в УФ) — согласуется с
  «0 = не называть, чёрный, ничто».

## 7. ПЕРЕХОДЫ И ПРАВИЛА

- **0→1 (рождение).** Первый разрыв симметрии: `Q|0⟩=0 → ⟨φ⟩≠0`; появление стрелы (необратимость),
  `â†|0⟩=|1⟩`. В CERN-слое: `b=0 → b=1` (триггер принял событие). Овал 0 → направленная 1.
- **9→0 (сброс с памятью).** Коллапс на вакуум `ρ₉→|0⟩⟨0|`, но `ε≠0`: сохраняется фаза Берри, число
  намотки `w→w+1`. Поэтому новый 0 = овал, не круг. Замыкание — **спираль**.
- **Правило:** 0 сам переходов не выбирает (генератор); он даёт **начальное условие** и **память** для
  следующего витка. Канал (буква А) должен быть открыт, иначе перехода 0→1 нет («нет связи ⇒ b=0»).

## 8. ГРАНИЦА УНИВЕРСАЛЬНОСТИ

- 0 как **единица группы / вакуум / память** универсально везде (любая группа, любая открытая система).
- **Где ломается наивная универсальность:** отождествление вакуумной энергии `Σ½ℏω_k` с наблюдаемой
  тёмной энергией Λ даёт расхождение ~**120 порядков** (проблема космологической постоянной) — прямого
  равенства НЕТ. Сюда «лезть не надо» на уровне фундамента: это открытая проблема, а не правило перехода.
- Также: «память вакуума» и «ε как параметр порядка» — за границей доказанного (см. поле 5).

## 9. ЭКСПЕРИМЕНТ / ПРОВЕРКА

- **Вакуум реален:** Казимир (Lamoreaux 1997; Mohideen–Roy 1998), динамический Казимир (Wilson 2011).
- **Память-как-фаза реальна:** фаза Берри (Tomita–Chiao 1986).
- **Память среды (немарковость) измерима:** BLP-backflow, RHP.
- **Предсказания модели (открыты):** гистерезис вакуумного шума ≠0; двухполюсное ядро памяти ↔ «два
  фокуса»; мягкая угловая мода `ω²∝` эллиптичности.
