## 1. ЧТО ЭТО

Строится **единая онтология («путь»)**, в которой числа 0–9 — это операторы одного универсального
процесса перехода. Источник — аллегорические описания чисел и букв из «контактных» транскриптов 1990-х
(«Смысл Букв», «Числа Паспорт», серия DIALOG 01–10, «Машина Числа», «Единая Теория»). Задача: **вытащить
из каждого слова аллегории физику**, собрать в один инструмент, где всё работает на одинаковых
соотношениях, и показать **границу**, где универсальность кончается и начинается «многообразие».

## 2. ЖЕЛЕЗНЫЕ ПРАВИЛА МЕТОДА (не нарушать — на этом уже спотыкались)

1. **Аллегория = истина-подсказка, НЕ «недоказанная физика».** Не сортировать «где аллегория, где
   физика». Из каждого слова **вытащить физику**. Аллегорию оставлять **дословно и целиком** — для сверки.
2. **Если перевод противоречит измеренному — неверен ПЕРЕВОД, не аллегория.** Найти правильную физику,
   а не отбрасывать слово.
3. **Не «подклеивать» под готовую физику там, где наша физика не достаёт.** Новый горизонт живёт в
   зазорах. Если не переводится — пометить «не нашёл», спросить автора (он переведёт). Не выдумывать.
4. **Не завешивать «отметками честности» (◇/✓/○ и т.п.).** Давать конкретную математику/физику и
   **названные опыты** (эксперимент + автор + год). Автор это специально просил.
5. **Числа НЕ одинаковые.** Единица хранит всё → **зеркало (двойственность) → ДЕЛЕНИЕ** → каждое
   следующее число = дальнейшее деление. Одинаков не каждое число, а **ПУТЬ**: одни соотношения, одна
   динамика, **память динамики**. Путь уже существует везде (найден как теорема, не выдуман).
6. **Проверять всё.** Реальные ссылки (arXiv/DOI), реальные опыты. Скептик-проверка обязательна.
7. **Память — центр.** «Электрон = не частица, а намотанная память» (динамика-геометрия памяти).
   «Эфир» = структура вакуума (Хиггс/нулевые колебания), НЕ механический эфир с выделенной системой
   отсчёта (тот убит Майкельсоном–Морли). Якоря памяти: геометрическая фаза Берри, голономия, winding;
   zitterbewegung; спин-½ с возвратом на **720°** (двойное накрытие SU(2)).

## 3. ОНТОЛОГИЯ (каскад деления)

`0 (вакуум/память) → 1 (хранит всё, стрела) → зеркало → 2 (первое деление, обратимо) → 3 (два мира +
третий) → 4 (обоюдная связь/спин) → 5 (зеркало 2, седло) → 6 (замкнутая ложная яма) → 7 (разрыв 6, порог)
→ 8 (развилка/сборка) → 9 (конец/необратимо) → 0 (сброс со памятью = спираль, winding w+1).`
Инвариант — **соотношения и переходы**, а не сами числа. «Остальное — разнообразие, разворачивающее уровень».

## 4. ТРИ ГЕОМЕТРИЧЕСКИЕ ОПОРЫ («откуда рождаются линии»)

- **Гармонограф** (Ashton, *Harmonograph*): число = **соотношение** (1:1, 2:1, 3:2, 4:3, **5:3**, …) =
  фигура. **open phase = круглое, closed phase = острое = ОДНО отношение при фазе φ=0 / π/2** (не два
  объекта!). Вращение (concurrent/counter) даёт розетку с **a+b лепестками**. Затухающий маятник рисует
  **память динамики**; прецессия розетки = намотка. Рациональное отношение → замкнутая фигура;
  иррациональное (золото 5:3→φ) → не замыкается, заполняет («золотое заполняет»).
- **5 Платоновых тел** — статический костяк формы; развёртка начинается с **тетраэдра** (R²=3).
- **720° (спин-½, SU(2))** — «наше»: возврат только после двойного оборота = память полного цикла.

## 5. СКЕЛЕТ ВОДОРОДА (область универсальности) + куда садятся числа

Одноэлектронный водород точно решаем (симметрия SO(4)/SO(4,2)). Числа:
- **1 = n** (главное), **3 = ℓ** (орбитальное; ℓ=1=p=2 доли=форма «3»), **5 = m** (магнитное; ℓ=2=d=5
  значений m=число «5»), **4 = спин** (σ_z, «четвёртое число» Дирака).
- **0** = вакуум/референс/память; **2,6** = декогеренция; **7** = порог перехода; **8** = равновесие/сборка;
  **9** = Ридберг n=9/конец; **10** = спираль-сброс.
- **Проявляется только ДРОБЬ:** `E_n=−Ry·(1/n²)`; спектр = разность дробей `1/n₁²−1/n₂²`. Целые n,ℓ,m —
  **генераторы** («за миром»); дробь — то, что существует «здесь». Цвет = длина волны перехода:
  видимое (Бальмер, n→2) начинается с n=3 = «мир чувств»; n→1 (Лайман) = УФ = невидимо = «0/1 чёрные».
- **Переходы и правила:** дипольные Δℓ=±1, Δm=0,±1; серии; конкретные **7→2 (Бальмер), 7→3 (Пашен)**.
- **Граница универсальности:** ломается на тонкой структуре (α²), лэмбовском сдвиге (2s–2p ≈1057 МГц),
  многоэлектронности, континууме. Дальше — «многообразие, куда на уровне фундамента не лезем».

## 6. ЧИСЛО → ФУНКЦИЯ (уже установлено)

Функция числа k = **развёртка катастрофы A_k** (Том–Арнольд, потенциал V=x^{k+1}, коразмерность k−1)
= **мультиплет водорода 2ℓ+1**. «Число раскрывает многообразие». **7 катастроф** (4 куспоида A + 3
омбилики D). Семьи по модулю 3: {1,4,7}·{2,5,8}·{3,6,9} (косеты ℤ₃; {3,6,9}=ядро).
Ключевые совпадения формы: **5 = −I·2** (зеркало, седло/Ирншоу ∇²=0); **9 = −I·6** (поворот 180°);
**7 = разрыв замкнутой 6** (порог); **8 = две ветви** (сборка cusp); **0 = овал = память** (два фокуса,
½ℏω, фаза Берри).

## 7. ФОРМАТ КАРТЫ (одинаковый для всех чисел)

1. **Аллегория дословно** (целиком, нетронуто — для сверки).
2. **Перевод: каждое слово → физика** (без сортировки).
3. **Место в пути** (из чего делится, во что; соотношение-инвариант).
4. **Память динамики** (что число хранит от пути; голономия/фаза).
5. **Геометрия** (гармонограф: соотношение→фигура, open/closed фаза, лепестки).
6. **Где путь уже работает** — **названные опыты** + ссылки (проверка).
7. **Связи.**
