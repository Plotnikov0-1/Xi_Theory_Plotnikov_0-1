## 2. ПЕРЕВОД: каждое слово → физика

| слово/оборот дословно | физика (вытащенная) |
|---|---|
| «мало острых граней, но у основания» | почти гладкая эволюция с **особенностью у дна**: нулевые колебания **½ℏω**, дно потенциала недостижимо |
| «фундамент… вы не знаете… для вас он остр» | основное состояние-опора; прямого доступа к дну нет — **ΔxΔp≥ℏ/2** (нельзя «положить» систему на дно) |
| «расшибаете лбы, пытаясь достичь» | запрет классического покоя на дне (неопределённость), барьер у минимума |
| «научитесь играть, театр жизни» | **суперпозиция ролей**: кубит `cos(θ/2)\|0⟩+e^{iφ}sin(θ/2)\|1⟩`; оператор X переставляет роли `\|0⟩↔\|1⟩` |
| «чем плавнее, тем меньше плыть и жить» | сильнее связь со средой (γ↑) → быстрее **декогеренция**, короче жизнь когерентности `τ_dec~1/(g²⟨n⟩)`; сглаживание = усреднение (среднее поле), подавление флуктуаций `Var~1/N` |
| «подстроиться под любого и каждого» | взаимодействие со **средним полем** / произвольным оператором среды; **частичный след** `Tr_E` |
| «станете иными — цифры будут значить другое» | **контекстуальность**: смысл оператора зависит от состояния/базиса; смысл зависит от масштаба (перенормировка) |
| «не законченный круг» | **открытый контур**: off-diagonal `ρ_ij≠0`, когерентность ещё цела (в отличие от замкнутого 0/6) |
| «есть время вернуться… шанс вернуться» | **ОБРАТИМОСТЬ**: унитарность `U(−t)=U†(t)`; T-симметрия; возврат Пуанкаре; **спиновое эхо в 2τ**; эхо Лошмидта — пока `t<t_деког.` |
| «2 наоборот, при зеркале» (из 5) | **зеркало −I** = операция деления пары; 2 и её отражение — начало ± |
| «в 2 раза хуже» (11) | удвоение неустойчивого; резонанс/вырождение двух копий |
| «II = два начала», «не более трёх» | аддитивная двоичность; кратность ≤3 |

*Точность перевода (не «отбраковка»):* «начало декогеренции» — не резкий миг: на малых временах
когерентность спадает **квадратично** (зеноновский режим), экспонента `e^{−Γt}` включается после времени
корреляции среды `τ_B`. То есть «2 = начало» = переход зенон→марков, а не мгновенная точка.

## 3. МЕСТО В ПУТИ (каскад деления)

- **Из чего:** из **1** (хранит всё) через **зеркало** (двойственность) → **первое деление** на два.
- **Соотношение (инвариант):** 2 = **пара ±**, которая ещё **не разошлась окончательно** («не законченный
  круг») → **обратимая** развилка. Это отличает 2 (обратимо) от 8 (разошлось на две замкнутые ветви) и
  9 (необратимо). Зеркало здесь только НАМЕЧЕНО; явно оно встанет в 5 («2 наоборот»).
- **Во что делится:** двоичность порождает **третий** (2→3: «два мира + обязательный третий»); в геометрии
  розетки 2:1 уже даёт **3 лепестка** (2+1) — тройка зашита в двойку.

## 4. ПАМЯТЬ ДИНАМИКИ

2 = стадия, где **память пути ещё полностью восстановима**. Off-diagonal `ρ≠0` = запись фазы цела;
**спиновое эхо** буквально пересобирает состояние в `2τ`, обращая накопленную фазу (`φ_i→−φ_i`);
эхо Лошмидта `M(t)=|⟨ψ₀|e^{iH₂t}e^{−iH₁t}|ψ₀⟩|²`, `M=1` при точном обращении. Намотка ещё не заперта
(в отличие от 9, где winding `w→w+1` фиксируется). **«Шанс вернуться» = немарковский возврат фазы.**

## 5. ГЕОМЕТРИЯ (соотношение → фигура; гармонограф)

Соотношение **2:1 (октава)**. Ровно подтверждает аллегорию двойки:
- **open phase (круглое)** = незамкнутая восьмёрка = **«не законченный круг»**;
- **closed phase (острое)** = V с **острым остриём внизу** = **«острые углы у основания»**.
- **Круглое/острое = одно отношение 2:1 при фазе φ=0 vs φ=π/2** — не два объекта, а две фазы.
- **rotary counter-current 2:1 = 3 лепестка** (a+b) — деление уже указывает на 3.
- Физика под розеткой: рациональное 2:1 → **замкнутая** орбита; так рождается устойчивая фигура (в 5:3
  и золотом — не замкнётся, заполнит; см. `AVOSKA_LISSAJOUS.md`). Прецессия розетки = намотка = память (поле 4).

## 6. ГДЕ ЭТОТ ПУТЬ УЖЕ РАБОТАЕТ (проверка, со ссылками)

**Энергия / уровень n=2:**
- `E_2=−13.6057/4=−3.4014 эВ`; первое возбуждённое состояние (Bohr, Phil. Mag. 26, 1 (1913)).
- **Серия Бальмера** (n→2, ВИДИМО): Hα 656.28, Hβ 486.13, Hγ 434.05, Hδ 410.17 нм, предел 364.6 нм
  (Balmer 1885; NIST ASD). Видимый цвет включается на переходах к n=2 — согласуется с картой 0/1
  (n→1 Лайман = УФ, невидимо).
- Вырождение `g=2n²=8`; впервые ℓ≠0 (2p). **Лэмбовский сдвиг** 2s₁/₂–2p₁/₂ ≈ **1057.8 МГц** (Lamb–
  Retherford, Phys. Rev. 72, 241 (1947)) — КЭД. **Метастабильный 2s** τ≈0.12 с (2γ) vs 2p τ≈1.6 нс.

**Обратимость («вернуться»):**
- Унитарность `U(t)=e^{−iHt/ℏ}`, `U(−t)=U†` (Stone, Ann. Math. 33, 643 (1932)). T-симметрия: `Θ=U_TK`,
  `Θ²=(−1)^{2s}` (Крамерс) (Wigner 1932). Возврат Пуанкаре/квантовый (Bocchieri–Loinger, Phys. Rev.
  107, 337 (1957)). Джейнс–Каммингс коллапс-возрождение (Eberly et al., PRL 44, 1323 (1980); эксп.
  Rempe–Walther 1987). **Спиновое эхо в 2τ** (Hahn, Phys. Rev. 80, 580 (1950)). Эхо Лошмидта (Peres,
  PRA 30, 1610 (1984)). Обращение времени в ЯМР `H_eff≈−H_dd/2` (Rhim–Pines–Waugh, PRB 3, 684 (1971)).

**Двойственность (двухуровневая):**
- Кубит `H=C²`, матрицы Паули `[σ_j,σ_k]=2iε σ_l`, спин-½ (возврат при **4π=720°**, спинорность),
  сфера Блоха, осцилляции Раби, `T₂≤2T₁`, no-cloning (Wootters–Zurek, Nature 299, 802 (1982))
  (Nielsen–Chuang 2010; Sakurai §3.2).

**Начало декогеренции / «подстроиться, сгладить»:**
- GKLS/Линдблад `dρ/dt=−(i/ℏ)[H,ρ]+Σγ_k(L_kρL_k†−½{L_k†L_k,ρ})`, `γ_k≥0`=полная положительность
  (Lindblad 1976, DOI:10.1007/BF01608499; GKS 1976). Вывод Дэвиса (слабая связь). Дефазировка
  `ρ_ij∝e^{−Γt}` (Zurek, RMP 75, 715 (2003)). Пространственная декогеренция `ρ(x,x')∝e^{−Λt(x−x')²}`
  (Joos–Zeh, Z. Phys. B 59, 223 (1985)). Среднее поле Кюри–Вейсс, `Var~1/N` (Friedli–Velenik 2017).
