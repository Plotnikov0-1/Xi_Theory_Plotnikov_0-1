# АВОСЬКА / ЛИССАЖУ 5:3 — сфера-самосетка (сводка, для других чатов)

Документ фиксирует итог по «авоське» — сферической фигуре Лиссажу 5:3.
Он самодостаточен: другой чат может продолжить отсюда, не восстанавливая контекст.

**Ярусы честности:**
◇ доказано точно (математика/код) · ✓ установленная физика · ≈ совпадение (не доказательство) · ○ интерпретация/чтение · ★ флаг/исправленная ошибка.

**Главный принцип:** соотношение первично, число вторично; **совпадение ≠ подтверждение.**
И: **авоська (5/10/φ) и часы (12, кубическое) — ДВЕ РАЗНЫЕ структуры. Их нельзя силой сливать.**

---

## 0. Откуда авоська (источник)

○ Из текстов 1997 года («контакт»/монолог): Земля в **авоське** (сетке-верёвке);
пересечения нитей сетки = **узлы** («где происходят проблемы»); полюса = **ручки**
авоськи; «вспомни интерференцию волн» → это и есть фигура **Лиссажу**.
Это чтение источника (○), не вывод — но оно однозначно задаёт объект: **сферический
Лиссажу**, а не плоский.

---

## 1. Что такое авоська математически ◇

Плоская фигура Лиссажу `{sin(bt)·cos(at), sin(at)}` **поднимается на сферу** добавлением
глубины (обратной стороны):

```
x = sin(bt)·cos(at)
y = sin(at)
z = cos(bt)·cos(at)      ← «копия с обратной стороны»
```

Тогда **x² + y² + z² = 1 тождественно** (◇, проверено символьно) — нить лежит ровно на
сфере. «Копия с обратной стороны», о которой говорил автор, — это компонента `z`:
та же плоская тень, но на задней полусфере. Источник приёма: Erb, arXiv:1802.06546.

Для авоськи берём **a:b = 5:3** (отношение автора; «минимум самоподобия 3,5,1»).

---

## 2. Экватор: сколько пересечений? — ОКОНЧАТЕЛЬНО ◇

Вопрос автора: «беру экватор и именно пересечение нитей… может 10… может 5… если это
шар, а здесь 2д авоська в проекции шара? оставить 5 и 3.»

Ответ — **и то, и другое, это два разных счёта одного факта:**

- Нить пересекает плоскость экватора **2a = 10 раз** (10 проходов) при t = k·π/5.
  Координаты x этих проходов:
  ```
  x(k) = ± {0, sin36° = 0.588, sin72° = 0.951}
  ```
- Но проходы идут **парами «перёд + обратная сторона»** (та же (x,y), разный знак z).
  Схлопывая перёд и зад, получаем **5 РАЗЛИЧНЫХ точек** на экваторе:
  ```
  x ∈ { −0.951, −0.588, 0, +0.588, +0.951 }   → 5 точек = ПЯТИУГОЛЬНИК
  ```

**Итог: 10 проходов → 5 различных точек (пентагон).** «5 или 8/9/10» — путаница в том,
что считать: проходы (10), различные точки (5). Правильно: **5** (и это ложится на
авторское «оставить 5 и 3»).

★ Ранние варианты «9 операторов на экваторе» — это был другой счёт (кольцо-параллель
через все пересечения); он не устоял. Держим **5**.

---

## 3. Золотой экватор: φ появляется сам ◇ (гипотеза H4 — подтвердилась)

Отношение крайних точек экватора:

```
sin72° / sin36° = 0.951 / 0.588 = 1.61803… = φ
```

**φ выходит из самой фигуры**, без подгонки (◇). Это и есть «золотой экватор».
Причина простая: 5 точек по 72° — это пентагон, а пентагон/декагон — носители φ
(диагональ/сторона = φ). Авоська = **золотой/пятиричный мир**.

---

## 3-бис. УДВОЕНИЕ — рабочий фундамент: 10 операторов, декагон ◇ (уточнение автора)

Автор: «количество операторов на экваторе увеличить вдвое, и соответственно волн; нужно
увеличить количество нитей». Проведено честно:

- **БАЗА:** a=5, **волн b=3** → экватор = **5** операторов (пентагон 72°). 8 нитей.
- **УДВОЕНО (фундамент):** a=5, **волн b=6** → экватор = **10** операторов (декагон 36°). 12 нитей.

Удвоили **только волны** (b: 3→6), оставив a=5. gcd(5,6)=1 — **не вырождено**.

★ **Ловушка:** 5:3 → 10:6 удваивать НЕЛЬЗЯ (gcd=2: нить дважды проходит те же 5 точек,
удвоения нет). Правильно — удвоить только b.

✓ **φ сохраняется, на более твёрдом ярусе:** у декагона R/сторона = 1/(2·sin18°) = φ
РОВНО (◇). Раньше φ жил в пентагоне (sin72/sin36) и в ≈-истории «5:3 Фибоначчи»;
теперь — в декагоне (◇). Обмен ≈ на ◇ — честнее.

◇ **Нити задают ЧАСТОТЫ, не диапазон t.** Период кривой ровно 2π (проверено:
|P(t+2π)−P(t)|<1e-13). Оригинальный `t∈[0, LCM(a,b)·π]` (=30π для 5:6) — это плотная
**обводка** (15 проходов), она НЕ добавляет нитей, только делает линии солиднее. Чтобы
реально добавить нити — поднимают частоты: 5:6→12 нитей, 8:5→14, 13:8→24.

Модуль-фундамент: `qmt/sphere_nodes.py` (A=5, B=6). Картинка: `report/shar_dve_lineiki.html`.

## 4. Полная 2D-проекция и широтная структура ◇

Проекция всей нити (не только экватора) на плоскость даёт **10 долгот через 36°** —
это **декагон** (10-угольник). Расстановка чисел по этим 10 (+ полюса) — вот откуда
у автора «получаются как будто часы», но с шагом 36°, а не 30°.

Узловая структура (численно, 120 000 точек выборки):

| широта z | что это | сколько |
|---|---|---|
| z = ±1 | полюса (ручки авоськи) | по 6 |
| z = ±√3/2 ≈ ±0.87 | верхнее/нижнее кольцо | по 12 |
| z ≈ 0 | экватор | 15 = 3×5 |

- Все узлы садятся на **10 долгот через 36°** (декагон → φ).
- Экватор — **5 долгот через 72°** (пентагон → φ).
- Змейка от полюса до полюса делает шаг **108°** (угол пентаграммы).

## 5. Два счёта: часы (12) против авоськи (золото) — ГРАНИЦА ◇/○

Автор считает фигуру двумя способами — их **нельзя путать**:

| | ЧАСЫ | АВОСЬКА |
|---|---|---|
| счёт | по чётным «зубьям» (как на циферблате) | змейкой от полюса до полюса, острые углы |
| число | **12** | **5 / 10** |
| симметрия | кубическая (звезда {12/5}, mod-3 семьи) | **золотая/пятиричная** (пентагон, декагон, φ) |
| шаг долготы | 30° | 36° (полная) / 72° (экватор) |
| статус | отдельная структура | отдельная структура |

○ Почему «12 как будто всегда входят»: 12-часовой циферблат — это *другая* разметка
той же сферы (кубическая), удобная глазу. Но **родная** симметрия авоськи 5:3 —
**золотая (5/10)**, не 12. Форсировать «авоська = 12» ★ нечестно (нарушает собственный
принцип автора: соотношение первично).

---

## 6. Узлы = операторы перехода ○

○ Пересечения нитей — это «узелки переходов» / операторы (по источнику: «где
происходят проблемы»). Как различать узлы между собой — открытый вопрос (K-ключ):
кандидаты для признака — широта (полюс/кольцо/экватор), чётность прохода (перёд/зад = знак z),
номер долготы. Пока это интерпретация, не доказано.

---

## 7. Что проверяемо / держим — что нет

**Держим (◇):**
- лифт на сферу точен (x²+y²+z²=1);
- экватор = 5 точек (пентагон); 10 проходов → 5 после схлопывания перёд/зад;
- sin72/sin36 = φ (золотой экватор);
- полная проекция = декагон (10, шаг 36°); кольца на ±√3/2; шаг змейки 108°.

**Держим как интерпретацию (○):**
- источник (авоська 1997, ручки=полюса, узлы=проблемы);
- узлы = операторы перехода; «обратная сторона = копия» = компонента z.

**НЕ держим (★):**
- «5/3 = φ» — нет, 5/3 = 1.667 — это фибоначчиев сосед, не φ (φ=1.618). Сходимость
  3/2→5/3→8/5→φ есть (лестница), но **сам** 5/3 ≠ φ.
- «авоська = 12/кубическая» — нет, она золотая (5/10).
- «9 операторов на экваторе» — нет, 5.

## 8. Код (воспроизвести)

```python
import numpy as np
a, b = 5, 3
# экватор: t = k·π/5, k=0..9  → 10 проходов
xs = [round(np.sin(b*(k*np.pi/5))*np.cos(a*(k*np.pi/5)), 3) for k in range(10)]
# xs = [0.0, -0.951, -0.588, 0.588, 0.951, 0.0, -0.951, -0.588, 0.588, 0.951]
distinct = sorted(set(xs))          # → [-0.951, -0.588, 0.0, 0.588, 0.951]  = 5 точек
print(0.951/0.588)                  # → 1.618… = φ  (золотой экватор)
```
